# SUBSLIDE · 把整条字幕轨拖回正轨

单文件、零依赖的 SRT 字幕重同步工具。打开页面、丢入字幕文件、像 DAW 里拖音频块一样在时间轴上拖动整条字幕轨——然后导出修复后的 `.srt`。全部处理在浏览器本地完成，文件不离开你的电脑。

**在线使用：** https://xiangjianan.github.io/daily-tools/subslide-20261006/

## 解决什么问题

字幕不同步是高频痛点：下载的字幕整体慢 2 秒，或者因帧率不同而越播越偏。桌面剪辑软件（Aegisub、Subtitle Edit）太重，为 10 秒钟的修正不值得；而多数在线「字幕平移」工具要求你**先把文件上传到别人服务器**。

## 怎么用

1. **载入** —— 选择 `.srt` 文件或直接粘贴内容。顶部时间轴会画出原始位置（蓝）和调整后位置（琥珀）。
2. **平移** —— 在时间轴上按住拖动（鼠标/触屏均可），或用 ±30 秒滑杆微调。偏移量实时作用于每一条字幕。
3. **双参考点同步（修漂移）** —— 如果字幕是「越播越偏」（帧率不匹配），单纯平移救不了。找出两句字幕、记录它们**实际应当出现**的时刻，输入序号 + 实际时间。SUBSLIDE 对全片拟合线性映射 `t → k·t + b`，一步同时修正偏移和速度差。
4. **导出** —— 一键复制或下载 `fixed.srt`。前后对照表会标出每一条被移动的字幕。

## 技术说明

- 纯前端：单个 HTML 文件，无构建、无 CDN、无网络请求，`file://` 双击即用。
- 解析器宽容：BOM、CRLF、缺序号行、`.`/`,` 毫秒分隔、时间倒置（修复保留并提示）都能处理；无法识别的块会跳过并计数提示，绝不静默丢弃。
- 双点拟合对极端输入做了钳制（参考点重合等退化情况自动降级为纯平移）。
- 时间轴 canvas 适配高分屏（DPR），指针事件统一支持鼠标、触控笔和触屏。
