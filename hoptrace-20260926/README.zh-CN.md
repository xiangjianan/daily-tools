# ✉️ HOPTRACE — 邮件头 X 光机

**粘贴原始邮件头，即时看到投递路线跳数时间线、SPF/DKIM/DMARC 判定，以及大白话钓鱼红旗。100% 本地运行——数据绝不离开浏览器。**

🔗 **在线使用**：https://xiangjianan.github.io/daily-tools/hoptrace-20260926//

## 解决什么问题

一封邮件看着不对劲时，证据都在邮件头里——但原始邮件头是一墙 `Received:` 噪音，而流行的在线分析器偏偏要你粘贴最不该交给第三方的数据：**你的内网主机名、中继 IP 和路由拓扑**。

## HOPTRACE 做什么

- **跳数时间线** —— 自动展开折叠头、解析 `Received:` 链，从最新到最旧渲染：谁碰过这封信、走的什么协议、**每一跳之间在路上花了多久**。
- **认证判定** —— SPF / DKIM / DMARC 徽章，汇总成一句大白话结论：`✓ NO RED FLAGS`、`⚠ SUSPICIOUS` 或 `☠ DANGEROUS`。
- **红旗检测** —— Reply-To 指向与 From 不同的域名（经典钓鱼手法）、DMARC/SPF 失败、时间戳倒流或晚于 Date 头、中继长时间停滞、内网 IP 泄漏。
- **Markdown 报告** —— 一键复制干净报告，直接贴进 IT 工单或事件记录。
- **两个内置样例** —— 干净的邮件列表路线 vs. 教科书级钓鱼邮件，两下点击看出差别。

## 怎么用

1. 打开页面。
2. 在 Gmail 中：打开邮件 → ⋮ → **显示原始邮件** → 复制正文以上的全部内容。（Apple Mail：显示 → 邮件 → 所有标头；Outlook：文件 → 属性 → Internet 邮件头。）
3. 粘贴，点 **TRACE ⛓**，看时间线和判定。

## 隐私

单个 HTML 文件，零依赖，零网络请求。每个字节都在你浏览器标签页里解析——邮件头恰恰是会泄漏邮件基础设施的数据，所以 HOPTRACE 绝不上传任何内容。加载一次即可离线使用。

## 技术说明

- 邮件头折叠展开（RFC 5322 续行）、`Received:` 子句解析、RFC 2822 日期解析（非标准格式有手工回退）。
- 内网 IP 检测覆盖 RFC 1918、回环、链路本地及 IPv6 ULA/链路本地。
- 启发式规则刻意保守：邮件列表合法地使用不同 Return-Path 域名，所以那只是提示（note）而不是警报。
