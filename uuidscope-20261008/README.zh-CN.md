# UUIDSCOPE — UUID 解剖镜

粘贴一批 UUID，立刻看清每颗 ID 的真身：版本、变体，以及最有意思的部分 —— v1 / v6 / v7 内嵌的时间戳，画成时间带，顺带检测乱序与重复。

## 解决什么问题？

UUID 看着是不透明串，其实大多带结构：

- **v7**（新一代默认，PostgreSQL 18 已内置）头 48 位就是 Unix 毫秒时间戳 —— ID 本身就是时间。
- **v1 / v6** 内嵌 60 位 1582 纪元时间戳，而且 v1 常常泄漏**生成机器的 MAC 地址**。
- **v2** 携带 POSIX UID/GID 和域。

按 v7/v6 ID 排序就等于按创建时间排序 —— 除非某些 ID 乱序了，UUIDSCOPE 会直接在时间带上标红。它还会告诉你哪颗 v1 正在泄漏真实 MAC。适合调试种子数据、追溯一行记录的创建时间、或验证 API 真的给了你新鲜的 v7。

## 怎么用

1. 双击打开 `index.html`（file:// 直接可用）。
2. 粘贴一颗或多颗 UUID（换行、逗号、空格分隔均可），解析即时完成。
3. 看统计徽章、内嵌时间带、逐条解剖明细。
4. 点「复制报告」拿到完整 Markdown 文本报告。
5. 「生成 v4 / v7」按钮直接往输入框追加新 ID。

全部在浏览器本地完成 —— 无网络请求，数据不出设备。

## 技术说明

- 单 HTML 文件，零依赖零构建，原生 JS + CSS。
- v1/v6 的 60 位时间戳用 BigInt 解析（安全越过 2^53）；v7 头部按 Unix 毫秒读取。
- RFC 9562 版本/变体位判定，nil/max 保留值识别，v2 DCE 字段提取。
- 乱序检测：对时间承载型 ID 比较输入顺序与内嵌时间顺序。
- 响应式下探 ~360px，支持触屏。

## 诚实声明

本工具只做结构解剖：无法还原 v3/v5 的名字（哈希不可逆），也不验证 UUID 是否真的由声称的系统签发。
