# MOJIFIX 🔧

粘贴乱码文本，即时诊断是哪种编码读错了它，并一键还原原文——附带 `锟斤拷` / `烫烫烫` 经典梗检测。单文件、零依赖、100% 本地运行。

**在线使用：<https://xiangjianan.github.io/daily-tools/mojifix-20260925//>**

## 解决什么问题

只要碰过中文文本的开发者都见过乱码：UTF-8 字节流在某个环节被当成 GBK 或 Windows-1252 解码，`测试现场` 变成了 `娴嬭瘯鐜板満` 或 `æµ‹è¯•çŽ°åœº`。原始数据往往还能救回来——但要弄清**到底哪一层读错了**（有时还嵌套两层），再手工反向还原，只能在不同在线工具之间反复试错，还得把数据上传给第三方。

## 工作方式

- 粘贴乱码，输入即诊断
- MOJIFIX 把文本经 GBK、Windows-1252、Latin-1 **反向映射**回字节流（包括**双层嵌套**损坏，如 GBK→CP1252→UTF-8），再按 UTF-8 解码，用可读性评分器排序（GB2312 字频分层、控制符/替换符惩罚、文字系统合理性）
- 一键**复制**或下载还原结果；全部候选解码按得分排名，展开即见
- 经典梗检测：`锟斤拷`（UTF-8 替换符被再读成 GBK——真正不可恢复）、`烫烫烫`（MSVC 0xCC 栈填充）、`屯屯屯`（0xCD 堆填充）
- 损坏不可逆时如实告知（在你看到的乱码**之前**数据就已被销毁）

## 隐私与技术

- **全部在浏览器本地完成。** 不上传、无统计、无网络请求——专有日志和代码片段也能放心粘贴
- 单个 `index.html` + 一个生成的数据文件（`gbk-rev.js`，GBK 字符→码位反查表，由 `gb18030` codec 生成——因为 WHATWG 的 "gbk" TextDecoder 就是 gb18030 双字节区）
- 零构建、零 CDN，`file://` 双击即用；鼠标 + 触屏友好，小屏手机响应式

## 用法

打开 <https://xiangjianan.github.io/daily-tools/mojifix-20260925//>，粘贴乱码（或点一个经典样本按钮），复制结果。就这么简单。

## 已知限制

- 只还原**被 GBK / Windows-1252 / Latin-1 误读的 UTF-8**（一至两层）。其他损坏（字节已被压成 `?` 或 U+FFFD）会检测出来并如实报告不可恢复
- 未覆盖 Big5 / Shift-JIS 误读链（仅 GBK 表就约 250 KB，为了保持工具轻量）
