# NAILMAP · 挂画定位器

输入一次，钉点全知。NAILMAP 把「买了 3 幅画 + 一面白墙」变成一张精确到毫米的钉点施工单——钉一次到位、挂得端正，墙上不再多出要补的孔。

## 解决什么问题？

挂一组画是看似简单实则繁琐的数学：画组要对齐视线高度（画廊标准 145cm）、间距要均匀，还得把每幅画「挂钩在框背的位置」换算成钉子的离地高度和距墙缘距离。多数人靠目测，结果挂歪一排、多补两个孔。NAILMAP 在一屏内算完：

- **墙面立面图** —— SVG 侧视图：画框、145cm 视线中线虚线、170cm 人形比例尺，每颗钉点用十字圆圈标出（N1、N2…）。
- **钉点施工表 + 可复制清单** —— 每幅画给出：钉点离地高度、距墙左缘距离、与前一画的间距、画框左缘偏移。一键复制整份施工单，打印按钮输出干净的纸质清单页。
- **挂钩自动填** —— 挂钩离画框顶边的距离默认取框高的 1/4（画越高钩越靠下），可手动改。
- **布局模式** —— 一排，或自动配平的网格（如 5 幅 → 上 3 下 2、末行居中）；画组超出墙宽或画框低于地面都会显式告警，绝不静默给错数。

## 怎么用

1. 设置画框数量、宽高、间距、视线中线（默认 145cm）、墙宽、挂钩偏移——滑杆或数字框都行。
2. 看立面图，再看下方钉点施工表。
3. 点「复制施工单」（或打印），先钉 N1，校平后再钉其余。

所有计算全部在浏览器本地完成。无上传、无账号、无网络请求。单文件 HTML、零依赖——双击即用。

## 技术说明

- 纯 HTML + CSS + 原生 JS 单文件（≤600 行）。布局引擎是一个小型纯函数（`computeLayout`），覆盖一排与网格两种排布，非法输入自动钳制并告警。
- 钉点模型为**单钩无松弛**：钉点离地 = 中线高度 − 画框高÷2 + 挂钩偏移。钢丝挂画受拉后会比钉点低 1–3cm，UI 与清单里如实说明，并建议用手机水平仪复核。
- 复制走异步 Clipboard API，`execCommand` 兜底并检查返回值，成功失败都有可见 toast。
- 打印样式隐藏控件与图形，只在白底上输出清单。
