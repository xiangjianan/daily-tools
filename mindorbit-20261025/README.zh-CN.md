# MINDORBIT · 思维星轨 —— 大纲变放射思维导图

粘贴一份缩进大纲（或 Markdown 标题），立刻得到一张**表盘式放射思维导图**：根在圆心，分支像星轨一样呈扇区展开，每条主支一个色相。点击折叠/展开、自由缩放平移，一键导出独立 SVG。全程本地，零上传。

**在线使用**：<https://xiangjianan.github.io/daily-tools/mindorbit-20261025/>

## 解决什么问题

文本是记录结构最便宜的方式——会议纪要、发布计划、读书笔记、打包清单——但一屏缩进列表看不出想法的形状。经典思维导图工具都是左→右树形布局，要注册登录，导出一张图还得绕过层层菜单。有时候你只想：**文本进，结构图出，文件到手，结束。**

## 怎么用

1. 在左侧输入或粘贴大纲，以下写法随意混用：
   - 缩进（2 空格 / Tab）表示层级；
   - Markdown 标题井号（`#`、`##`、`###`），井号数量即层级；
   - 列表符号（`-`、`*`、`•`、`1.`）自动剥离。
   - **首个顶格行会成为圆心**。
2. 边打字边重绘，顶栏实时显示节点数 / 层级数 / 末端数。
3. 交互：
   - **点击节点**折叠或展开分支（节点上方 `+N` 徽章提示隐藏数量）；
   - **悬停**某条分支，其余分支变暗，一次只读一条脉络；
   - **滚轮 / 双指**缩放，**拖拽**平移，`⌂` 一键适配全图；
   - **＋ / －** 按钮步进缩放（触屏友好）。
4. **下载 SVG** 保存独立深色画布 SVG（不依赖外部字体，可直接插进文档 / README / 幻灯片）；**复制 SVG** 则把代码放进剪贴板。
5. 🎲 **示例** 内置两份演示大纲；**清空** 后画布给出友好提示。

数据从不离开浏览器：解析、布局、渲染、导出全部本地完成——页面加载后离线也能用。

## 技术说明

- 单文件 `index.html`，零构建、零依赖、不引 CDN、不发任何网络请求。
- 解析器：Tab 归一为 2 空格，剥离标题井号与列表符号，跳过无实义符号行（`***`、`###`、`- - -`），栈式建树。
- 布局：按叶子数比例分配时钟扇区角——子树越密弧越宽，标签互不打架；层级越深环间距自动收紧。
- 连线是沿局部法向弯曲的二次贝塞尔曲线，按顶层分支色相着色（10 色相调色板，深色主题调校）。
- 交互用 pointer 事件委托实现（悬停高亮靠切换 `dim` 类而非重渲染，不闪烁、重绘不丢监听）；单指平移、双指捏合走统一的指针映射。
- 导出时把视口组重新序列化为全新 SVG（按内容包围盒 + 深色底），得到独立矢量文件。
- 鼠标与触屏都支持；窄屏下编辑器与画布上下堆叠的响应式布局。
