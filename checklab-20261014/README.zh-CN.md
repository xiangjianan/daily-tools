# CheckLab · 校验位实验室

[English](README.md) | 简体中文

粘一串号码，看它过不过校验位这一关。CheckLab 自动识别你丢进来的号码类型，把校验位背后隐藏的加权求和算术逐位画出来，红绿判定——还能一键造一个同类型的合法测试号。

## 解决什么问题？

校验位无处不在——支付表单、IMEI 锁、书号、跨境转账、身份证号——但藏在背后的数学完全不可见。表单拒掉一个号码时，你根本不知道是数字抄错了还是算法另有要求。CheckLab 把这套算术变可见，一位一位地展示，全程在你浏览器里完成。

## 支持的算法

| 类型 | 算法 |
|---|---|
| 银行卡（Visa、Mastercard、Amex、JCB、Discover、Diners、银联…） | Luhn（ISO/IEC 7812-1） |
| IMEI 手机串号 | 15 位 Luhn |
| EAN-8 / EAN-13 商品条码 | Mod-10 加权 3,1 |
| ISBN-13 书号 | 同 EAN-13（978/979 前缀） |
| ISBN-10 书号 | Mod-11 加权 10…2，允许 X |
| 中国居民身份证（18 位） | GB 11643 加权求和，mod-11 查表 |
| IBAN 国际银行账号 | ISO 13616 重排 + mod 97 = 1 |

歧义长度诚实处理：13 位号码同时给出 EAN-13 与银行卡两张判定卡；15 位给出卡号与 IMEI 两个候选。每个候选各有一张独立的验算卡。

## 怎么用

1. 每行粘一个号码（空格、连字符、点、下划线会自动忽略）。
2. 每个候选渲染成一张验算卡：类型徽章、绿/红判定，点击展开逐位加权求和的算式拆解。
3. 用下方生成器面板随机造一个**合法**的测试号——调试表单时特别好用。

所有计算都在浏览器本地完成。不上传、无网络请求、无统计埋点。

## 技术说明

单文件 HTML5 + 原生 JS + CSS，零构建、零依赖，双击即用、离线可用。校验位数学全部是纯函数（48 条断言的仿真套件验证过；生成器自证——每颗造出的号码都过一遍自家检测器）。深度内容渐进展开：卡片默认折叠，点开才看逐位算式。
