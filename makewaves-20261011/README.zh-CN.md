# MAKEWAVES

English | [简体中文](README.zh-CN.md)

> 注：本文件为中文版说明，英文版见 [README.md](README.md)。

粘贴一个 Makefile，立刻看到它的**执行波次图**——`make` 真实运行你的目标时的顺序，以及 `make -j` 下哪些目标会并行。

**在线使用：** https://xiangjianan.github.io/daily-tools/makewaves-20261011/

## 解决什么问题

Makefile 是伪装成纯文本的执行计划。读文件能看出谁依赖谁，但看不出：

- `make -j` 要跑几轮才能完成最终目标；
- 哪些目标会真正并行执行；
- 有没有依赖环在暗处潜伏；
- `make` 为什么把某个目标选成默认目标。

MAKEWAVES 把不透明的计划变成可见的：每条横向泳道是一波——同一波里的目标依赖已同时就绪，`make -j` 会并行执行它们。

## 功能

- **波次图**——目标按拓扑层级排布：叶子目标（纯文件规则）在 `WAVE 0`，默认目标落在最后一条泳道。泳道数 = 关键路径长度；最宽的一条 = `make -j` 的峰值并行度。
- **依赖闭包高亮**——点击任意目标，高亮它（传递地）需要的全部目标，无关目标变暗。详情面板展示直接依赖、反向依赖（"被谁需要"）和变量展开后的配方。
- **环检测**——环上目标渲染进红色 `CYCLE` 泳道（make 拒绝执行它们），并给出成员清单警告。
- **诚实解析**——支持 `\` 续行、注释、变量（`=`、`:=`、`?=`、`+=`）与递归 `$(VAR)` 展开、多目标规则、行内 `;命令`、`.PHONY` 徽章、模式规则（标记但不出图）。解析不了的行会明确报告，绝不静默丢弃。
- **一键 Markdown 执行计划**——把整套波次表复制成 Markdown 清单，贴进 PR 描述或文档。
- **100% 本地**——纯前端、零依赖、零网络请求。Makefile 永远不离开浏览器。支持把 `.mk` 文件拖进输入框，或直接粘贴。

## 怎么用

1. 打开页面（双击 `index.html` 离线可用）。
2. 粘贴你的 Makefile，或点「载入示例」。
3. 读波次；点目标查看闭包；点「复制执行计划」导出。
4. 点「载入带环反例」可以看环标记效果。

## 支持的 Makefile 子集

变量、规则、phony 目标、模式规则、注释、续行、多目标规则、行内配方。不支持（会明确报告或忽略，不会误解析）：`include`、`export`/`unexport`、`$@` 以外的自动变量展开、`$(shell …)`、归档成员、`::` 双冒号语义（按普通规则解析）。

## 技术说明

单文件 HTML5 + 原生 JS + SVG。零构建、零 CDN、零 Cookie、零统计。解析器、波次计算（DFS 带环标记）、闭包与反向依赖索引，共约 200 行无依赖 JavaScript，全部在浏览器本地运行。
