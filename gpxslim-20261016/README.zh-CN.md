# gpxslim · GPX 轨迹瘦身台

把 GPS 轨迹文件（.gpx）拖进来，立刻看懂它——再把它变轻。

## 解决什么问题

GPS 设备和手机 App 默认几秒记一个点，一天的徒步轻松攒下 5000+ 个 `<trkpt>`、好几 MB 的文件：地图 App 打开卡顿，公开分享还悄悄暴露你家住哪。**gpxslim** 是一个单页工作台：

- **画出轨迹**：暗色画布地图（等距柱状投影按均值纬度缩放），起点/终点标记 + 航点圆环
- **报出体征**：总距离（haversine 球面距离）、累计爬升/下降、时长、均速、点数
- **画高程剖面**：剖面可滑动——悬停或拖动，地图上游标联动，实时读出里程/海拔
- **轨迹瘦身**：迭代式 Douglas–Peucker 精简，一根滑杆实时显示「1,400 → 214 点（−85%）」和预计体积变化
- **导出**瘦身后 GPX（保留海拔和时间戳），喂给性能弱的地图 App 或放心分享

## 怎么用

1. 打开 `index.html`（或 GitHub Pages 地址），拖入 `.gpx` 文件——或点「载入示例轨迹」看一条程序生成的山地环线
2. 看统计卡片；在高程剖面上滑动，检查线路上任何一点
3. 拖「轨迹瘦身」滑杆，直到点数和线形都满意
4. 点「导出瘦身 GPX」，下载件保留海拔与时间戳

没有 `<ele>` 的文件优雅降级（剖面显示提示，爬升/下降显示 —）；没有 `<time>` 只隐藏时长/均速；非法坐标自动跳过；多个 `<trkseg>` 自动拼接。

## 技术说明

- 单 HTML 文件，零依赖、零构建，`file://` 双击即用
- 全部处理都在浏览器本地：解析（DOMParser）、几何（haversine、投影平面上的迭代 Douglas–Peucker）、渲染（Canvas 2D，适配 DPR）——**轨迹不向任何地方上传一个字节**
- 剖面滑动用 Pointer 事件，鼠标触屏通吃；布局响应式到 390px
- 精简阈值按轨迹自身最大偏差归一，滑杆在小轨迹和大轨迹上手感一致
