# SQUISH 🔩

**粘贴一段文字，看看它里面有多少「空气」。** SQUISH 会在浏览器里实时跑一遍 gzip 压缩和香农熵分析，然后用一枚判定徽章告诉你：你的文字到底有多啰嗦。

## 解决什么问题

冗余是看不出来的。你的 system prompt 是不是很臃肿？那份 README 是不是全是套话？你的文本会不会白白烧 LLM token？压缩率是衡量重复度最诚实的指标——但没人会为了这个专门开终端敲 `gzip`。

## 怎么用

1. 把任意文字粘进输入框（或点 **Load sample** 加载示例）。
2. 就这样，结果立刻出现：
   - **判定徽章**——🧱 BRICK（几乎压不动）→ ☁️ FLUFFY → 🎈 BALLOON（大量重复填充），太短的文本则给出 🍞 CRUMB
   - **尺寸 X 光**：原始 / gzip / 理论熵下限三重对比，能看出 gzip 离物理极限还有多远
   - **统计**：词数、词汇丰富度、平均词长、粗略 LLM token 估算
   - **重复雷达**：出现 3 次以上的单词和词组
3. 点 **Copy report** 导出纯文本报告。

## 为什么它是诚实的

- gzip 数字是浏览器原生 `CompressionStream` API 的真实压缩结果，不是猜的、也不是拍脑袋的启发式。
- **熵下限**是 0 阶香农熵的理论极限。gzip 与下限之间的差距，就是 gzip 的滑动窗口够不到的结构——对较真的人来说这是个很有意思的数字。

## 隐私

100% 本地。没有服务器、没有上传、没有统计埋点。你的文字永远不离开浏览器标签页——这很重要，因为最值得「压一压」的往往是最私密的东西：prompt、草稿、邮件。

## 技术说明

- 单个 HTML 文件，零依赖，零构建，`file://` 双击即用、离线可用。
- gzip 走 `CompressionStream`（Chrome/Edge 80+、Firefox 113+、Safari 16.4+）；旧浏览器自动降级为仅统计模式。
- 鼠标触屏皆可，响应式布局，深色主题。
