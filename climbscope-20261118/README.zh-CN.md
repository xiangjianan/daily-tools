# ⛰️ CLIMBSCOPE — GPX 爬坡剖面仪

单文件浏览器工具：把任意 GPX 轨迹拖进来，立刻得到一张**坡度染色海拔剖面图**，并按环法标准自动给每段爬坡**分级**（4 类 → 1 类 → HC）——纯本地解析，零上传。

**在线使用：** https://xiangjianan.github.io/daily-tools/climbscope-20261118/

## 解决什么问题

骑行、徒步、越野跑的人手边全是 GPX 文件，但裸 XML 什么也看不出来。「这条线到底有多虐？」通常意味着装个桌面软件、把轨迹传给陌生网站，或者在 Strava 那点大的剖面图上眯眼猜。

## 功能

- **拖入 `.gpx`** → Canvas 即时渲染海拔剖面
- **坡度染色**：剖面每一段按坡度绿 → 黄 → 橙 → 红渐变着色，虐点一眼可见
- **自动识别爬坡段**：短暂起伏（落差 < 15 m、间隔 < 400 m）不会把一座坡切碎
- **环法式分级**：按海拔增益 × 平均坡度加权评分，分为 4 类 → 3 类 → 2 类 → 1 类 → HC
- **任意点游标**：悬停/触摸剖面读取里程、海拔、即时坡度；点爬坡卡片可在图上单独高亮该坡
- **一键导出 PNG** 剖面图，方便分享
- 内置**演示轨迹**，手边没文件也能玩

## 怎么用

1. 打开页面（可离线、双击即用、手机可开）
2. 拖入 `.gpx`（Garmin / Strava / Keep / 两步路导出均可），或点「加载示例轨迹」
3. 看统计条（总里程、累计爬升/下降、海拔范围、最狠坡段），在剖面上下游走，点爬坡卡片
4. 需要分享就导出 PNG

## 技术说明

- 纯 HTML + 原生 JS + Canvas，**零依赖、零 CDN、零网络请求**
- 浏览器内用 `DOMParser` 解析 GPX；半正矢公式累计里程；中值滤波（窗口 5）抹平 GPS 海拔毛刺
- 爬坡识别：连续上升且坡度 ≥ 3%、增益 ≥ 60 m 的段落，短间歇自动合并
- 缺失 `<ele>` 的点线性插值补齐；非 GPX 文件、无海拔轨迹均给出友好报错
- 响应式布局，鼠标 + 触屏，深色主题
