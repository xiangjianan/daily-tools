# OHMBAND · 电阻色环解码台

色环电阻就是用油漆写成的科学计数法。OHMBAND 把这套编码变成双向可读：在电阻上点任意色环循环换色、即时读值；或输入 `4k7` / `2M2` 这类工程写法，看正确的色环点亮。全部计算在浏览器本地完成。

## 解决什么问题

靠记忆读色环很容易错——红色到底是数字 2 还是 ×100 的倍率？网上计算器要么是笨重的多下拉框表单，要么根本不给你看"每个环在干什么"；而反方向（4.7 kΩ 该用哪几个环？）几乎没人支持。OHMBAND 直接把电阻本体当界面：每个环点一下，读值立刻出来，双向都通。

## 怎么用

1. **色环 → 阻值**（默认）：点电阻上任意色环（或下方的色块）循环换色——数字环循环 0–9，倍率环循环 ×0.01–×10⁹，容差环循环 ±0.05%–±10%。阻值、容差和实际最小/最大范围实时刷新。
2. **阻值 → 色环**：切换模式后输入任意常见工程写法：`4.7k`、`4k7`、`2M2`、`10R`、`0.47`、`100m`（R 是小数点，m = 毫欧）。色环点亮并吸附到最近的 E24（4 环）或 E96（5 环）标准值，同时显示吸附偏差。
3. **标准值候选**：最接近的 5 个标准值带偏差百分比以色块列出，点一下即采用。
4. 可切换 **4 环 / 5 环** 模式，点 **随机来一颗** 随机解码一颗电阻，或 **复制读值** 一键复制完整摘要。

## 技术说明

- 单文件 HTML + 原生 JS + CSS，零依赖、零构建，`file://` 双击即用。
- 纯函数内核：`bandsToValue`、`parseValue`（正则解析工程写法）、`snapSeries`（最近 E24/E96 有效数字）、`valueToBands`、`candidatesNear`。全部本地计算——无网络、无存储。
- 往返验证：两个序列共 158 个标准值全部通过「编码 → 解码还原原值」。
- 响应式布局、≥40px 触控目标、深色主题。
