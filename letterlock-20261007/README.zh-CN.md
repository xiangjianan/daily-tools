# LETTERLOCK · 密信胶囊

写一段密信、设一个密码，铸出一个**自带解密器的单文件 HTML 胶囊**。把这一个文件发给对方：任意浏览器打开、输入密码即可阅读。不装软件、不注册、不联网——文件本身就是应用。

**在线使用：** https://xiangjianan.github.io/daily-tools/letterlock-20261007/

## 解决什么问题

想在聊天里发一段敏感内容（密码、告白、恢复助记词），它会永远躺在聊天记录、云端备份和对方的服务器上。全盘加密或 PGP 能解决，但对普通人和**收信人**都太重了。

LETTERLOCK 把整个流程压缩成一个产物：密文嵌在 HTML 里、解密器也附在同一个文件里。收信人只需要一个浏览器。

## 怎么用

1. **铸造**：写好信、设好密码（可附一条**明文**密码提示），点「铸造胶囊」，下载生成的 `letterlock-capsule.html`——或者只复制那串密文发过去也行。
2. **开启**：对方打开胶囊文件、输入密码、读信，全程离线。密码错一个字符？AES-GCM 校验直接失败，不存在「蒙一下就开」。
3. **当场验证**：工具页上点「在本页试开」就能把刚铸的胶囊回环试解，发出去前先自测。也可以把胶囊文件拖回「开胶囊」面板，密文会被自动提取并本地解密。

## 技术说明

- 密钥派生：PBKDF2-HMAC-SHA256 × 310,000 次迭代 + 16 字节随机盐 → AES-256-GCM，每颗胶囊 12 字节随机 IV。全部走浏览器原生 WebCrypto，没有自造密码学。
- 密文格式：`LKLK1.` + base64(JSON `{v, it, s, iv, c, h?}`)，原样嵌入胶囊文件。GCM 认证标签让篡改和错密码同样不可区分——都直接失败。
- 密码强度条是诚实的熵下界估计（字符集 × 长度），不是营销数字。
- 100% 纯前端：单个 HTML 文件、零依赖、零构建、`file://` 双击即用。铸出的胶囊本身也是无任何外部引用的单文件——拷进 U 盘，2036 年照样能打开。

## 诚实的边界

- 可选的密码提示以**明文**存在胶囊里，别把密码本身写成提示。
- 这个工具证明的是「知道密码」，它拦不住收信人转发明文，也拦不住有人无限次试密码——密码请设长一点（强度条会告诉你多长）。
- 不验证「发信人是谁」——防的是内容泄露，不是身份伪造。
