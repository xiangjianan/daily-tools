# 调休日历 TIAOXIUCAL — 今天上班吗？

[English](README.md) | 简体中文

**调休日历**，打开第一眼就回答那个每周都要问一遍的问题：**今天上班吗？**——内置国务院官方放假调休安排，日历上的每个周六周日到底上不上班，一眼看清。

## 解决什么问题

中国的假期有个所有日历软件都说不清的 twist：周末会被「调」——为了凑长假，某个周六突然变成工作日。于是每年都在重复同样的问题：「下周六到底上不上班？」「到截止日还有几个工作日？」「下一个真·休息日是哪天？」调休日历把这三个问题变成打开页面就能看到的答案，全程零联网。

## 功能

- **秒答判定** — 打开页面即出大字「上班 / 不上」，附原因（法定假 / 周末补班 / 普通周末……）；赶上假期中，还会告诉你这是假期的第几天。
- **下一个假期倒计时** — 距离下次休息还有几天。当年官方假期全部过完？会继续倒计时到下一个固定法定日（元旦 1/1、劳动节 5/1–5/2、国庆 10/1–10/3，《全国年节及纪念日放假办法》规定年年必休），并诚实标注「连休安排待公布」。
- **全年调休地图** — 12 个月 mini 日历热力图：法定假实红、调休连休浅红、被调来上班的周六琥珀色带「班」角标、普通周末灰色、自定义标记绿色。点任意一天看它为什么上班/休息。
- **区间工作日计算** — 选两个日期，出自然天数 / 上班天数 / 休息天数 / 其中周末 / 其中补班，并列出途经的假期。结果一键复制。
- **自定义补班/放假** — 公司自己的调休、官方安排未公布年份的临时调整，都能手动标记（存 `localStorage`，优先级最高）。

## 怎么用

浏览器打开 `index.html` 即可（双击就能用，无需服务、无需构建、无需联网）。当前数据为 2026 年官方安排（《国务院办公厅关于2026年部分节假日安排的通知》国办发明电〔2025〕7号，2025-11-04 发布）。农历节日（春节、清明、端午、中秋）在未公布年份不做猜测；固定公历法定休息日照常内推。

## 技术说明

单文件 HTML，原生 JS + CSS，零依赖，全部计算在浏览器本地完成。数据即官方通知里的十几行日期。`dayStatus()` 按严格优先级链判定任意日期：自定义标记 > 官方假期 > 固定法定日内推 > 周末补班 > 普通周末 > 工作日。
