# ProseWave · 文案心电图

[English](README.md) | 简体中文

粘贴文本，看到文章的"心电图"——每句话变成一根波形条，好文章有起伏呼吸，坏文章是一条催眠直线。

## 解决什么问题？

Gary Provost 的经典论断：连续五句词数相同的句子，读者会睡着。可写作者在写的时候**看不见**自己的节奏。ProseWave 把"句子长度的变化"变成即时波形 + 大白话诊断：

- **节奏波形** — 每格一句、越高越长；鼠标悬停或点击任意一格，可读这句原文。
- **诊断卡** — 节奏健康 / 节奏偏平 / 等长句连击（连续 N 句长度几乎一样，Provost 警报）/ 失控超长句（>120 字）。
- **统计面板** — 句子数、平均/最长/最短句长、波动系数 CV（>0.35 说明节奏有起伏）、最长等长连击。
- **问题清单** — 值得拆分的臃肿长句、短句爆发，并定位到第几句。
- **Markdown 报告** — 一键复制完整诊断，贴进笔记或代码评审。

中文、英文、混排都支持：CJK 字符按字计数，拉丁文按词计数。

## 怎么用

1. 浏览器打开 `index.html`（双击即可，无需服务器）。
2. 粘贴你的稿子，或点一个样例（好节奏 / 单调节奏 / 中文小说）。
3. 悬停波形读原句，看诊断结论，复制 Markdown 报告。

## 技术说明

- 单文件 HTML + 原生 JS + CSS。零依赖、零构建、零网络请求。
- 句子切分为正则实现，完整识别中文终止符（。！？…；）与英文终止符（`.!?;`）。
- 全部处理在浏览器本地完成——文本绝不离开页面，隐私优先。
- 29 条断言的 Node 逻辑测试（`test_logic.mjs`）+ 16 项 Playwright 冒烟测试（`smoke.py`）。
