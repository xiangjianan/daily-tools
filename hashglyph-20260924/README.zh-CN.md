# HASHGLYPH

**每段文本都有一张脸。**粘贴任意内容——HASHGLYPH 用 SHA-256 计算指纹，并把它画成一眼就能认出来的对称彩色图腾。

**在线使用：**https://xiangjianan.github.io/daily-tools/hashglyph-20260924//

## 为什么做这个

哈希是看不见的。想知道两段文本——配置片段、license key、长 token、文件校验和——是否完全相同，你要么逐字读，要么对比一堆长得都一样的十六进制串。HASHGLYPH 把每个 SHA-256 摘要变成一枚对称的「印章」：字节相同，脸就相同；差一个字符，脸就完全不同。用眼睛完成比对。

它同时还是一个**雪崩效应**的直观演示：翻转末字符的一个比特，看 256 个输出比特里约一半随之翻转——这正是哈希指纹值得信任的核心性质。

## 用法

1. 在左侧输入或粘贴文本——图腾和完整 SHA-256 摘要随输入即时出现。
2. 在右侧粘贴第二段文本——徽章直接告诉你 **IDENTICAL（相同）** 还是 **DIFFERENT（不同）**，两张脸并排对比。
3. 点 **Flip the last character ↯** 看雪崩效应：比特翻转计数 + 两张毫无关联的脸。
4. 可以复制摘要，或把图腾存成 PNG（给任意字符串当确定性头像也挺好用）。

## 技术说明

- 单文件 `index.html`，零构建、零依赖、零联网——哈希在浏览器里用 WebCrypto 完成，并内置纯 JS 版 SHA-256 兜底，双击文件即可运行。
- 图腾把摘要的前 32 个比特装进镜像的 4×8 网格（所以左右对称），色相/饱和度/明度由摘要第 4–6 字节决定。2^256 种可能，实际上不会有两张相同的脸。
- 不上传、不存储、不记录任何数据，离线可用。
