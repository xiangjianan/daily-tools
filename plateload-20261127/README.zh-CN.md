# plateload — 杠铃配重装配台

[English](README.md) | 简体中文

**plateload** 告诉你任意目标重量下,杠铃每侧应该挂哪些片——还会把从空杆到目标重量的整个加载过程一步步排好。

## 解决什么问题

每个练力量的人都在组间做这道心算:"总重 82.5 公斤……空杆 20,片上 62.5,每侧 31.25……也就是 25 + 5 + 1.25。"算一次不难,一个训练日算四十次很烦,累了还容易算错。多数配重计算器只给一串结果;没有工具告诉你"怎么一步步挂上去"。

## 怎么用

1. 选单位(kg / lb)和空杆重量(20/15/10 kg 或 45/35 lb 预设)。
2. 输入目标总重量——或点一个快捷片。
3. 立即得到:
   - 一张**杠铃装配图**,竞赛风格的彩色片按比例画在两侧套筒上;
   - 一份**加载路线图**:第 0 步是空杆,之后每一步显示加哪对片、杆上总重变成多少,热身组间照着走就行;
   - 每侧配重与片数,一键复制成文字清单。

片组凑不出精确值时(比如 82.3 公斤),plateload 就近装载,并如实告诉你差多少,而不是装作没问题。

## 技术说明

- 单个自包含 HTML 文件。零构建、零依赖、零联网——全部在浏览器本地运行。
- 按常见商用片组(25/20/15/10/5/2.5/1.25 kg、45/35/25/10/5/2.5 lb)做贪心装载(大片优先),凑不齐时优雅降级为"就近装载 + 差额说明"。
- 响应式布局,触屏友好,双击 `index.html` 离线可用。
- 内置自测:在 URL 后加 `#selftest` 打开页面即可运行。
