# STAIRSCOPE · 楼梯剖面仪

输入层高，立刻得到所有可行的踏步方案——用有 400 年历史的 **Blondel 舒适公式**（2R + G ≈ 630 mm）逐一验算打分——外加实时绘制的楼梯剖面图：人形比例尺、坡度角弧、尺寸标注一应俱全。一键复制施工报告。

## 解决什么问题？

规划一段直梯（阁楼、复式、错层、改造）时，算数很磨人：2.8 m 层高能放几级踏步？哪组「踢面×踏面」组合真正走得舒服，而不只是「放得下」？电子表格和通用计算器只给你数字，STAIRSCOPE 直接给你看**楼梯本梯**。

## 怎么用

1. 输入层高——`2.8`（米）或 `2800`（毫米）都认。
2. 选一张方案卡（级数）。★ 推荐项是 Blondel 验算综合得分最优的。
3. 用滑杆微调踏步深 G（240–330 mm），剖面实时重绘。
4. 看三枚评级徽章（R / 2R+G / 坡度）和指标卡：投影长度、洞口参考、踏面数。
5. **复制报告**把全部数据导出成文本，发给施工方或直接当下料清单。

## 它验算的规矩

- **Blondel 公式**：2R + G ≈ 600–650 mm（目标 630）——17 世纪法国建筑师 Blondel 提出的步幅舒适经验式，至今仍是楼梯设计的通用验算方法。
- 踏步高 R：150–180 mm 舒适，190 mm 内可接受。
- 踏步深 G：最小 240 mm，滑杆范围 240–330 mm。
- 坡度：≤ 32° 轻松，≤ 38° 可接受。

落不进这些区间的方案不硬凑——工具会如实告诉你凑不出来，而不是硬塞一个难走的数字。

## 技术说明

- 单文件 HTML + 原生 JS + CSS，零构建、零联网、无 CDN——全部计算在浏览器本地完成，不传任何数据。
- 剖面图为程序生成的 SVG（任意 DPI 下都清晰），配 1.7 m 人形剪影给比例感。
- 踏面数 = 级数 − 1（顶层楼面即最后一级「踏面」）；投影 = 踏步深 × 踏面数；洞口参考另加 900 mm 休息平台，并明确标注仅供参考。
- 鼠标触屏双支持，响应式适配手机宽度，深色主题。
