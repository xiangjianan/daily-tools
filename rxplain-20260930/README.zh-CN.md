# Rxplain · 正则翻译官

[English](README.md) | 简体中文

粘贴一个正则表达式，看它被拆成一段段彩色卡片并翻译成中文白话；再输入一段测试文本，实时看清谁被谁匹配。

## 解决什么问题？

正则表达式是「写一次、再也不想读」的东西。regex101 用英文侧栏解释、regex-vis 画铁路图，但都不说中文，而且都要在「表达式」和「解释」之间来回跳。Rxplain 把**正则本身变成可视化对象**：每个记号变成一张彩色卡片（转义蓝色、字符类紫色、分组用琥珀色盒子框起来、量词红色），每张卡片配一句中文白话——「一个字母/数字/下划线」「重复 2 到 5 次、尽量少」「捕获组「user」：把这里匹配到的内容存起来」。

- **分段可视化** —— 嵌套分组渲染成带标签的盒子，量词紧跟它所重复的节点，多分支用「或者」分隔。
- **白话清单** —— 整条表达式的编号缩进式逐段讲解，一键复制成文本。
- **实时匹配高亮** —— 输入或粘贴测试文本，每处匹配就地高亮，配捕获组表格展示 `$1`、`$2`… 的值（命名组按名字显示）。
- **模式开关** —— g / i / m / s / u 五个标志，解释与匹配同步生效。
- **速查 chips** —— 8 条日常正则（邮箱、手机号、网址、日期、十六进制颜色、IPv4、重复单词、标签对）一键载入并附示例文本。
- **友好报错** —— 括号不配对、字符类没闭合、反斜杠悬空，都给中文提示而不是天书。

## 怎么用

1. 浏览器打开 `index.html`（双击即用，无需服务器）。
2. 粘贴正则，或点一条速查；读卡片和白话清单。
3. 在测试框里敲文本看实时高亮和捕获值；需要时复制整段解释。

## 技术说明

- 单文件 HTML + 原生 JS + CSS。零依赖、零构建、零网络请求。
- 手写递归下降解析器把正则切成树（字面量、转义、字符类、锚点、分组/断言、量词、多分支）；「树重建后必须与源串逐字符相等」的不变量由 36 条断言的 Node 测试（`test_logic.mjs`）覆盖，另有 Playwright 冒烟套件（`smoke.py`）。
- 匹配直接复用浏览器自带 `RegExp` 引擎——本工具只负责「讲人话」，不重新造匹配轮子。
- 全部处理在浏览器本地完成——你的正则和测试数据不出页面，隐私优先。
