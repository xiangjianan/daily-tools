# INKSIGN · 墨迹签名板（速度感应矢量签名板）

单文件签名板：把你的手写笔迹变成**真矢量 SVG**——笔画粗细随书写速度自然呼吸，像真正的墨水。

## 解决什么问题

常见签名板导出的都是定宽线条的位图截图：放大就糊、印刷发虚、复用进文档很别扭。INKSIGN 在你书写时读取**运笔速度**——写得慢笔画变粗、写得快笔画变细——并把每一笔输出为矢量轮廓填充，结果可以无限缩放，在打印、PDF、网页里都保持锐利。

## 怎么用

1. 直接在纸面上写：鼠标、手指、触控笔都行，落笔即画，零学习成本。
2. 可选微调：换墨色（墨黑 / 钢笔蓝 / 朱砂红 / 月白）、调笔锋粗细滑杆、撤销某一笔、切换纸面（米白 / 深夜）。
3. 导出：**SVG 下载**（矢量）、**PNG 下载**（2× 透明底）、或**复制 SVG 代码**直接粘进你的页面。
4. 没有灵感？点「来个示例签名」载入一段程序化笔花。

## 技术说明

- 零依赖、零构建、零网络请求——全部在你的浏览器本地完成。签名这种隐私数据本就不该上传。
- 笔迹模型：Pointer Events 采样 `{x, y, t}`；速度（px/ms）经指数曲线映射为目标笔宽，再用 EMA 平滑。每笔由线段法线构建变宽轮廓，渲染与导出都是一条带圆头笔帽的闭合贝塞尔路径。
- 支持鼠标 / 触屏 / 触控笔（Pointer Events + `touch-action: none`），响应式适配手机宽度。
- 单个 HTML 文件，约 530 行，双击即用。
