# 🎼 PITCHPOISE · 音准摆针 — 让音准看得见的浏览器调音器

**PITCHPOISE** 是一款带"颤音透视"的纯前端调音器：对麦克风哼一个音或弹一根弦，
摆针立刻摆向最近的半音并读出音分偏差，下方 4 秒颤音迹线实时画出你的音高波浪。
所有分析在本机完成——声音永远不离开你的设备。

## 解决什么问题？

大多数在线调音器只给你一个数字和一根针，却不解释为什么听起来"飘"。PITCHPOISE
可视化的不只是音高，而是音高**稳定性**：唱歌的人能亲眼看到自己的颤音波形，
吉他手调准时看到一条笔直的线；"定音挑战"把枯燥的调音练习变成 5 秒小游戏
（稳在 ±5 音分内计时，解锁徽章）。

## 怎么用

1. 打开页面，点 **🎤 开启麦克风**（Chrome/Edge/Safari，需 HTTPS 或 localhost）。
2. 稳定哼一个音或弹一根弦——摆针显示与最近音符的音分偏差；大字为音名，
   绿色代表 ±5 音分以内。
3. 盯住**颤音迹线**：波浪 = 颤音或气息不稳；绿带里一条直线 = 稳了。
4. 玩**定音挑战**：把任意音稳在 ±5¢ 绿带内，计时器记录最长稳住时长，
   1.5s / 3s / 5s 依次点亮 🌱→🎯→🏅 徽章。
5. 用 **A4 = 435–450 Hz** 滑杆校准不那么标准的钢琴；点 **🔊 听参考音** 播放
   A4 对照；**📋 复制报告** 把音符纸带 + 最佳纪录导出为文本。

人声、吉他、尤克里里、小提琴、卡祖笛都行——任何 60–2000 Hz 的声音。
无账号、无上传、加载后零网络请求，完全客户端运行。

## 技术说明

- 音高检测：时域自相关（ACF2+ 谱系）+ 抛物线插值做亚采样精度；RMS 底噪与
  清晰度双门槛过滤静音和噪声，有效范围钳制在 60–2000 Hz。
- DSP 核心（`core.js`）无 DOM 依赖，Node 单测 46 条断言：覆盖音名换算、
  E2–C6 检测精度、颤音跟踪、噪声拒绝与自定义 A4 校准偏移（`selftest.js`）。
- 端到端冒烟：无头 Chromium 注入合成 440 Hz WAV 假音频设备——完整流水线
  （getUserMedia → 自相关 → 摆针/迹线/纸带/挑战 UI）检出 A4 @ 441 Hz、
  定音 4.35 秒；权限被拒路径给出友好中文提示。
- 渲染：双 HiDPI 感知 canvas（摆针 + 迹线），音分 EMA 平滑防抖；
  无 Pointer 依赖，触屏鼠标都好用。
- 零依赖、零构建、零遥测。4 个文件：`index.html`、`style.css`、`core.js`、`app.js`。
