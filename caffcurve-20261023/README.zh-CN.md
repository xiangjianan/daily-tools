# CAFFCURVE ☕ — 咖啡因半衰期曲线

[English](README.md) | 简体中文

点几杯今天喝下的咖啡因，立刻画出体内的实时衰减曲线——并直接回答今晚唯一重要的问题：**「现在还能不能再来一杯？」**

## 解决什么问题

咖啡因记录类 app 要你每口都打卡、注册账号、把饮食习惯交给服务器。但真正的痛点不是「我喝了多少」，而是一个 *what-if 决策*：现在喝杯拿铁，23:00 点血液里还剩多少？今晚的睡眠要不要为之买单？大多数计算器要么甩给你一个孤零零的数字，要么把药代动力学整个藏起来。CAFFCURVE 把整条曲线放进一屏，并替你下判断。

## 功能

- **即时曲线**——点饮品 chip（意式浓缩 65mg、拿铁 75mg、美式/手冲 95mg、奶茶 100mg、绿茶 45mg、可乐 35mg、能量饮 80mg，或自定义剂量），体内负担曲线实时重画，带**现在**线、**就寝**线和 50mg/100mg 阈值参考线。
- **就寝判定**——红绿灯结论（绿 <50mg ≈ 清零 / 橙 50–100mg / 红 >100mg）配白话理由，外加「≈ N 杯意式浓缩」的比例尺。
- **最后一杯 deadline**——算出你今晚最晚几点喝一杯标准 100mg 还能在就寝时降到 50mg 线以下；若此刻已超标，则给出余量降回线下的倒计时。
- **代谢速度滑杆**——半衰期 3–8h，附快/标准/慢预设（4/5/7h）。CYP1A2 基因、吸烟、药物都会移动它，诚实的默认值是 5h 人群均值。
- **欢迎计划中的杯**——时间在未来的杯子到点前不计入，所以「16:00 那杯再喝会怎样」是原生问题，不是 hack。
- **复制报告**——一键导出文本摘要（摄入清单、此刻余量、就寝判定），存档或给医生看都行。
- **边界情况**——空状态引导、自定义 0/负剂量拒绝、就寝时间跨午夜按次日计算、手机端无横向溢出。

## 怎么用

1. 任意浏览器打开 `index.html`——`file://` 双击即用，完全离线。
2. 点今天喝过的饮品（时间默认现在，每行的时钟字段可改）。
3. 设好就寝时间；知道自己代谢快慢的话调一下滑杆。
4. 看曲线和判定，需要就复制报告。

## 技术说明

- 单文件 HTML5 + 原生 JS + Canvas，零依赖、零构建、零网络请求。
- 药代动力学：一阶消除，`余量 = 剂量 × 0.5^(经过小时 ÷ 半衰期)`，逐杯独立求和。标准单室模型——做决策辅助够用，不是医疗器械。
- 图表手绘在 DPR 感知的 canvas 上，曲线每分钟自动前进。
- 所有计算都留在你的浏览器里。什么都不上传，永远。
