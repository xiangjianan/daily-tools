⑤ 秤的刻度（规则出处：CSS Selectors Level 4）

  • 三车道：(A, B, C) = ID 数、类/属性/伪类数、类型/伪元素数。字典序比较，A 压一切。
  • :where(...) 一律记 0——括号里写 ID 也不加分，专为「让路」而生。
  • :is() / :not() / :has() 取括号里最重那个参数的权重。
  • 行内 style="" 相当于再多一档（1,0,0,0）；!important 更高一层；同权重看源码顺序，靠后者赢。
  • 通用选择器 *、组合符 > + ~、:hover 的父级不算数——它们零重量但改变结构。
