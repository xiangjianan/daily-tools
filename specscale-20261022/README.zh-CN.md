# SPECSCALE ⚖️ — CSS 选择器优先级天平

[English](README.md) | 简体中文

粘贴 CSS 选择器，看清**一条规则凭什么压过另一条**：三车道权重天平（ID / 类 / 类型）、逐片段白话解释、双选择器当场对决裁决。全部解析在浏览器本地完成。

## 解决什么问题

「为什么我的样式不生效」是 CSS 的头号高频问题。现有的优先级计算器只吐一个数字就完了，而真正容易踩的规则——`:where()` 一律记 0、`:is()` / `:not()` / `:has()` 取最重参数**替代**默认的 `(0,1,0)`、权重打平时看源码顺序——全都是看不见的。SPECSCALE 把这笔算术摊开给你看，还替你裁决对决。

## 功能

- **即粘即称**：得到 `(A, B, C)` 三元组 + 三条车道条 + 逐 token 的 chip 解释（哪个片段贡献了哪一票，`:is()` / `:where()` / `:has()` 括号里也算给你看）。
- **对决模式**：任选两个已上秤的选择器，宣布胜者、指出赢在哪条车道，并提醒平局按源码顺序判。
- **整段扫描**：粘一整段 CSS 自动提取选择器、上秤、从重到轻排名。
- **一键复制报告**：导出所有选择器的称重结果与对决结论。
- **非法输入友好处理**：悬空/连续组合符、未闭合括号、空的 `:is()`、无法识别的片段，都给出定位明确的提示，而不是给一个悄悄算错的数。

## 怎么用

1. 浏览器打开 `index.html`（`file://` 双击即用，无需服务）。
2. 每行粘一个选择器；或直接粘一段 CSS 规则块，点「从这段 CSS 提取」。
3. 看车道读数，挑两个进对决，复制报告走人。

## 技术说明

- 单文件 HTML + 原生 JS + CSS。零依赖、零联网、零构建。
- 手写选择器 tokenizer：跨组合符的复合段切分、括号配平扫描带参伪类、`:is()` / `:not()` / `:has()` / `:where()` 参数的递归权重（含 `:has(> img)` 这类相对选择器）。
- 权重语义遵循 CSS Selectors Level 4，已用规范自带示例表做 40 条自动化断言对拍。
- 不是完整 CSS 解析器：只读选择器文法，规则体的声明会被忽略；冷门语法（命名空间、转义边角）宁可诚实报错也不乱打分。
