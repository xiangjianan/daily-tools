# 路径解剖台 · SVG Path 解析回放器

粘贴一段 SVG path 的 `d` 属性字符串，它会被逐命令拆开：每条命令（M、L、C、S、Q、T、A、Z，含大小写相对/绝对）变成一张可点击的卡片，回放滑杆再一笔一笔把路径重新画给你看——控制点、锚点全程可见。

## 解决什么问题

SVG path 数据对大多数人是"只写不读"的：一串 `C 30 20, 50 20, 60 90 S 90 160…` 数字墙，`C`/`S`、`Q`/`T` 的反射控制点差别完全看不见，"曲线这里为什么打了个结"只能靠猜。路径解剖台把每一段画出来、放出来，你一眼就能看到哪条命令画了形状的哪一部分。

## 怎么用

1. 把 `d` 字符串粘进输入框（或点五个内置示例之一）。
2. 路径渲染在网格画布上，带起点/终点标记、锚点和控制点手柄。
3. 点清单里任意命令——其余部分变暗、该段高亮，控制点与牵引线显现，并给出这条命令在做什么的白话解释。
4. 拖动回放滑杆（或点 ▶ 回放）逐笔动画重画；右上角徽标显示当前命令和进度百分比。
5. **复制绝对坐标 path** 一键导出归一化后的全绝对 `d` 串（相对命令已展开）。

常见边角都已处理：科学计数法、`H`/`V` 简写、`M` 后链式坐标（隐式 lineto）、负半径、非法字符——都给出带位置信息的友好提示，而不是黑屏。

## 技术说明

- 单文件 `index.html`，零构建、零依赖、零网络请求——全部在浏览器本地解析渲染。
- 手写 tokenizer + 解析器：相对命令归一为绝对、计算 `S`/`T` 反射控制点、三次/二次贝塞尔与 SVG 椭圆弧（端点参数化→圆心参数化）采样供 canvas 绘制。
- canvas 按 devicePixelRatio 缩放，视图自动适配路径包围盒；响应式布局支持触屏。
- 已用 Node 逻辑仿真（23 条断言：段链一致性、`absoluteD` 往返重解析、弧半径不变量、反射数学、错误分支）+ Playwright 无头冒烟（零 console/page 报错、DOM 渲染断言、390px 移动端溢出检查）验证。
