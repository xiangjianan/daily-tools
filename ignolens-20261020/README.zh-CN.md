# Ignolens · .gitignore 判定透镜

粘贴 `.gitignore` 和一串文件路径，每条路径立刻判定**会被忽略还是保留**——并且能展开规则链看清「为什么」：每一级目录谁命中、否定规则在哪一步翻盘、以及那个著名的陷阱在哪触发（否定规则救不回父目录已被排除的文件）。

## 解决什么问题

`.gitignore` 背后是日常开发里最容易被误解的规则引擎之一：**最后命中的规则说了算**，否定（`!`）只在父目录没被排除时才有效，`**` 能匹配零层目录，不含斜杠的模式在**任意层级**生效。当你想提交的文件在 `git status` 里一直是灰色，通常的做法是拿 `git check-ignore -v` 反复试错——它只告诉你「赢的是哪条」，从不告诉你推理链。现有工具要么只管*生成* gitignore（gitignore.io），要么要求 CLI 熟练度。Ignolens 把判定过程可视化，一次粘贴全看清。

## 怎么用

1. 左侧粘贴 `.gitignore` 内容（打开页面自带一份示例）。
2. 右侧粘贴文件路径，每行一条。
3. 每条路径立刻得到判定徽章（**忽略 / 保留**）和一句话理由。点行展开规则链：逐级目录走查、命中的规则、以及「父目录已排除 · 不再向下走」的 ⚠ 标记。
4. 底部规则面板统计每条规则的命中数；点某条规则可高亮所有由它决定的路径。
5. **复制判定报告**一键导出整张判定表（Markdown）。

判定语义与 `git check-ignore` 一致（最后命中优先、父目录排除短路、锚定规则、`**` 语义、字符类）。

## 技术说明

- 单文件 `index.html`，零构建、零依赖、零网络请求——解析与匹配全部在浏览器本地完成。
- 手写模式编译器：gitignore 语法（注释、否定、尾 `/` 仅目录、首 `/` 锚定、含内 `/` 隐式锚定、`**` 的首/中/尾三种位置、不跨 `/` 的 `*` 与 `?`、带 `!`/`^` 否定的 `[...]` 字符类、反斜杠转义）→ JS 正则；再配合逐级前缀走查，实现 git 的「父目录被排除 ⇒ 不再向下」规则。
- 引擎用真实 `git check-ignore --no-index -v` 输出做先知对拍（21 条路径矩阵：否定翻盘、父目录陷阱、锚定、`**` 变体），并在 Chromium 无头环境复验通过。
- 响应式双栏布局，鼠标触屏均可。
