# ♞ BISHOPART

**粘贴一条 SSH 指纹，亲眼看"醉酒主教"走出 OpenSSH 的 randomart。**

## 它做什么

每条 SSH 密钥指纹旁边都有一幅奇怪的 ASCII 画——`ssh-keygen -lv` 输出的 "randomart"。几乎没人知道它是怎么画出来的：OpenSSH 把摘要的每个字节喂给一位想象中的**醉酒主教**，让它在 17×9 的棋盘上对角线踉跄，走过的格子层层叠叠，就成了那幅画。

BISHOPART 逐字节复刻了这个算法（与 `ssh-keygen -lv` 输出逐字符比对验证），并让它变得可观看：

- **看画** —— 支持 `SHA256:…`、`MD5:aa:bb:…`、裸 hex，或整行 `id_*.pub` 公钥（WebCrypto 本地哈希）
- **看走** —— 播放/暂停/单步走完全部 128 步对角线，速度可调，重复走过的格子有热度着色
- **统计** —— 步数、访问格子数、重访次数、最热格子
- **导出** —— 一键复制与 ssh-keygen 同格式的 ASCII 画，或下载 PNG

## 为什么

同一把钥匙 ⇒ 同一条路线 ⇒ 同一幅画。randomart 的意义是让人一眼认出服务器密钥，而不用逐字符比对 hex——但它的机制一直是个黑盒。BISHOPART 把它变成看得见的过程，也顺便科普了 OpenSSH 里最有趣的彩蛋之一。

## 怎么用

1. 打开页面（双击 `index.html` 即可，完全离线可用）
2. 粘贴指纹——或点一个示例按钮
3. 按 **▶ Walk**，看主教从 `S` 踉跄到 `E`
