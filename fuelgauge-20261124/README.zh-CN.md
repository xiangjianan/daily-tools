# ⛽ fuelgauge — 油耗台账解剖

粘贴你的加油记录，立刻看到**真实每箱油耗**、每公里成本和异常解读。全部在浏览器本地计算，数据不离开这台设备。

**在线使用：** https://xiangjianan.github.io/daily-tools/fuelgauge-20261124/

## 解决什么问题

大多数人的加油记录散落在备忘录里或者根本没有记录。油耗其实很难算对：只有**两次连续加满**之间的区间才能得出可信的整箱油耗，中间的非满箱加油必须归入这一段。fuelgauge 帮你把这笔账算清楚——与加油 App 同款的满箱分段法——并把数字变成图表和直白的解读。

## 怎么用

1. 每行一次加油，顺序随意（工具按里程表读数自动排序）。例如：

   ```
   2026-08-03 12050 km 42.5 L ¥352 full
   2026-08-24 12621 km 42.5 L ¥353 full
   2026-09-12 13180 km 40.0 L ¥332
   ```

2. 加满的那几行行尾加 `full`（或 满 / 加满）。你只需要记住这一个概念。
3. 结果随输入即时渲染：平均油耗（L/100km）、每公里成本、沿里程轴展开的箱油耗标尺、每箱明细表，以及标红的异常箱与可能原因提示。
4. 一键复制文字摘要或导出 CSV——全部本地生成。

**格式宽容度：** 日期可省略（支持 `YYYY-MM-DD`、`YYYY/MM/DD`、`MM-DD`）；单位可写 `km`、`公里`、`L`、`升`、`¥`、`元`、`yuan`，也全部可以省略（数字按位置推断）；分隔符随意。解析不了的行会友好提示并跳过，绝不崩溃。

## 技术说明

- **分段算法：** 只有「满箱 → 满箱」的区间算一个真实整箱。该箱消耗 = 区间内**加进去的所有油**（起点那次加的油支撑的是上一箱）。非满箱停靠只贡献金额与天数。
- **异常判定：** 某箱偏离均值 ±18% 以上即标红，并给出候选原因（胎压、空调季节、市区拥堵、驾驶习惯）。单箱异常是噪音，连续两箱同向偏离才是信号。
- **技术栈：** 单文件 HTML、原生 JS、零依赖、零构建。SVG 图表手写渲染。双击 `index.html` 离线可用。没有任何上传——根本不存在服务端。
