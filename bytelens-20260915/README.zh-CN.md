# BYTELENS — 在浏览器里给文件拍 X 光

把任意文件拖进页面，立刻看到它的**字节级解剖图**：可读文本在哪里、压缩噪声在哪里、内部还藏着什么格式。每个字节变成一个像素，文件变成一张地图。

**🔗 在线使用：https://xiangjianan.github.io/daily-tools/bytelens-20260915//**

## 解决什么问题

文件格式是个黑盒：这个「图片」是不是改名后的 ZIP？这个 10 MB 的文本文件为什么这么大？PNG 的压缩数据从哪结束、元数据从哪开始？命令行 hexdump 能回答，但对大多数人太不友好；而网上的「文件检查器」要求你**把文件上传到别人的服务器**。

## 功能

- **字节地图** — 1 字节 = 1 像素，按类型上色：零值（暗色）、ASCII 文本（青色）、空白符（钢蓝）、二进制/高熵（彩色噪声）。像浏览频谱图一样滚动整个文件。
- **全文件缩略图** — 一条窄带装下整个文件，点哪跳哪。
- **熵曲线** — 分块香农熵：平坦 = 纯文本或填充，尖锐炽热 = 压缩或加密数据。
- **格式签名** — 扫描头部区域的 17 种魔数（PNG / JPEG / ZIP / PDF / GZIP / 7z / RAR / MP3 / FLAC / OGG / ELF / EXE / SQLite / MP4 / WEBP / GIF / BMP），钉在地图上。2 字节弱签名（BM、MZ、GZIP）只在 offset 0 处采信，避免误报。
- **字节检查器** — 悬停或点击任意字节：偏移、十六/十/二进制、字符、类型、附近签名。
- **复制报告** — 一键生成纯文本摘要。

## 使用方法

1. 打开页面（双击本地文件即可，`file://` 直接用，无需服务器）。
2. 拖拽文件进来，或点击选择，或直接粘贴。
3. 自由探索：滚动地图、点缩略图跳转、悬停查看字节。

大文件只映射前 4 MB；文件的其余部分分毫不动。
