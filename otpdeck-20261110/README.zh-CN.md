# otpdeck · 本地一次性验证码生成器

纯浏览器本地计算的 TOTP（时间型一次性密码）生成器。把 `otpauth://` 迁移链接或裸 base32 密钥粘进来，当场算出当前的 6/8 位两步验证动态码，带 30 秒倒计时环。

## 为什么做它

带云同步的验证器 App 要求你把 2FA 种子交给第三方保管。otpdeck 站在对面：密钥永远不离开设备——全程零网络请求。打开页面、粘贴、复制验证码，三步完成。它适合这些场景：手机不在手边时；或者注册新账户时，先把二维码背后的 otpauth 链接粘进来核对一遍，确认无误再存进验证器。

## 用法

1. 打开 `index.html`（双击即用，无需服务器）。
2. 在文本框里每行粘一个账户：
   - `otpauth://totp/GitHub:me@example.com?secret=JBSWY3DPEHPK3PXP&issuer=GitHub`（所有两步验证设置页给出的标准迁移链接格式）
   - 或裸 base32 密钥：`JBSWY3DPEHPK3PXP`
3. 卡片即时出现：当前验证码、发行方/账户名、倒计时环；30 秒窗口滚动时自动翻码。
4. 点卡片即可复制。内置「载入示例」用的是 RFC 6238 附录 B 官方测试密钥——先验证算法没跑偏，再放心粘真实密钥。

格式错误的行会按行号报错；好行坏行混在一起时，好行照常出码。

## 技术说明

- 单 HTML 文件、零构建、零 CDN、零网络请求。
- TOTP 按 RFC 6238 实现（HMAC-SHA1/SHA256/SHA512 走 WebCrypto），动态截断按 RFC 4226，base32 解码按 RFC 4648——全部手写。
- 支持 otpauth URI 的自定义 `digits`（6/8 位）、`period`、`algorithm` 参数。
- 自动化 oracle 测试对拍了 RFC 6238 附录 B 全部 18 条测试向量（SHA1/SHA256/SHA512 × 6 个时刻）。
- 它不做的事：不能当备份——什么都不存储，刷新页面即清空。请把 otpauth 链接保存在你的密码管理器里。
