# ERGODESK · 工位人体工学尺

[English](README.md) | 简体中文

**ERGODESK** 把两个数字——你的身高和桌子的实际高度——换算成一套健康工位的黄金数值：座面高、桌面高、屏幕中心高、视距。侧视小人图随身高实时变形，差值补偿引擎在你和桌子不匹配时给出可执行的动作：椅子该升到几厘米、要不要脚踏（要多高）、桌腿要不要垫、显示器怎么跟着补。

## 解决什么问题

市面上的桌子大多是固定的 75cm，但人不是。网上的人体工学计算器只吐一串孤立数字，不管你家的桌子怎么办。ERGODESK 补上这最后一公里：先算黄金值与实际桌子的差值，再把差值翻译成具体动作——座面调到多少、脚会不会悬空（脚踏要几厘米）、桌子该垫还是该换、显示器如何同步补偿。

## 怎么用

1. 拖滑杆设置身高（130–210cm）。
2. 选坐姿或站姿模式。
3. 输入桌子实际高度（默认 75cm，最常见的桌高）。
4. 看黄金数值、色卡差值判定和分步调整建议。
5. 点 **复制工位调整卡** 得到文字版摘要，或 **打印** 存一份纸质版。

## 技术说明

- 单文件 HTML5 + 原生 JS + CSS，零构建零依赖，浏览器双击即用，完全离线。
- 全部计算与 SVG 绘制在浏览器本地完成，不发任何网络请求、不上传任何数据。
- 核心公式：座高 ≈ 0.25·H（腘窝高近似），桌高 ≈ 坐姿 0.43·H / 站姿 0.615·H，眼高 ≈ 坐姿 0.69·H / 站姿 0.936·H，屏幕中心略低于视线，视距 ≈ 0.36·H（收敛到 50–75cm）。均为人体测量学近似值，仅作参考，不构成医疗建议。
- 补偿引擎：差值 = 实际桌高 − 黄金桌高 → 高出 +2.5cm 以上给升椅/脚踏方案，低过 −4cm 给垫桌方案，±1.5cm 以内判定无需调整。
- 质量记录：核心引擎 28 项单测全过；DOM 冒烟覆盖 H∈{130,170,210} × {坐姿,站姿} 六种组合，SVG 全元素断言在画布内，console 零报错。
