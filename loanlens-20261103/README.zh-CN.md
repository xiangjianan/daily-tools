# LoanLens · 房贷放大镜

纯本地、零依赖的房贷 what-if 工具：并排对比等额本息与等额本金两种还款方式，把余额曲线和「本金首次超过利息」的交叉月份画出来，再一键预演提前还款能省多少利息、提前多久结清。

## 解决什么问题？

普通房贷计算器只告诉你月供，很少告诉你两种方式为什么利息差几万、你的钱到底从哪一期开始真正还的是本金而不是给银行付息。LoanLens 把这些抽象数字变成看得见的形状：

- **双卡片对比**——月供、利息总额、还款总额，等额本息 vs 等额本金一眼见分晓。
- **余额曲线图**——两条衰减曲线 + ▲ 标出各自的交叉点（单期还款中本金首次超过利息的月份）。
- **还款构成条带**——120 根堆叠柱直观展示利息（黄）逐月变薄、本金（青）逐月变厚。
- **提前还款 what-if**——输入「第 N 个月末多还 X 万」，选缩短年限或减少月供，立刻得到省息金额、缩短期数、每万元省息比。

## 怎么用？

1. 浏览器打开 `index.html`（双击即用，无需服务器、无需联网）。
2. 用输入框或滑杆调整贷款总额（万元）、年利率、年限。
3. 滚动到提前还款区，试算「第 N 期提前还」的效果。
4. 点 **📋 复制测算摘要** 复制纯文本结论。

## 技术说明

- 单文件 HTML（约 600 行），原生 JS + CSS，零 CDN、零构建、零后端。
- 全部等额本息/本金计算在浏览器本地完成，不向任何服务器发送数据。
- 标准公式：等额本息 `P·i/(1−(1+i)^−n)`；等额本金 `P/n + 余额·i`。提前还款对剩余本金重新摊还：缩短年限模式求解同月供下最短期数，减少月供模式保持剩余期数重算月供。
- 纯函数（`schedAnnuity`、`schedLinear`、`crossoverMonth`、`prepay`）不依赖 DOM，可独立单测。
