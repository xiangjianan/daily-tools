# FLYWATT · 充电宝飞行安检台

过安检前 30 秒自查充电宝：输入容量（mAh）与标称电压，或直接粘贴铭牌文字——即时换算额定能量（Wh），在 100/160Wh 三色标尺上定位，并跑完整套随身规则体检：≤100Wh / 100–160Wh / >160Wh 三档、携带块数口径、2025-06-28 起施行的 3C 标识要求、鼓包/破损/召回禁带项。顺带估算这只充电宝能给手机、平板、掌机或耳机盒回充几次。

## 解决什么问题

锂电池乘机规则真的容易糊涂：Wh 印得不显眼、100/160 阈值容易记混，而且 2025 年 6 月起「无 3C 或标识不清」这一条就足以让充电宝在安检口被拦下。官方没有提供计算器，搜索结果全是 SEO 长文。FLYWATT 把整个检查压缩成一次输入和一张判定卡，全程在浏览器本地完成。

## 怎么用

1. 在快速录入框粘贴铭牌文字，如 `20000mAh 3.85V` 或 `74Wh`（也可手动填容量与电压）。
2. 选择携带块数，切换 3C 标识与外观状态开关。
3. 查看判定徽章、三色标尺与逐条规则清单；点击设备筹码查看预计回充次数。
4. 复制「安检自述卡」，值机被问时直接出示。

## 技术说明

- 单文件 HTML + 原生 JS + CSS。零构建、零 CDN、零网络请求——所有计算在浏览器本地完成，不上传任何数据。
- 铭牌宽容解析：识别 `mAh/毫安`、`V/伏/volt`、直接标注的 `Wh/瓦时`；铭牌缺电压时按常见 3.7V 兜底并明确提示。
- Wh = mAh × V ÷ 1000；回充估算按 85% 转换效率计。
- 标尺为手写内联 SVG；规则与阈值参考民航局旅客携带锂电池乘机指南，页面明示「最终以现场安检为准」。
