# JWT 体检卡 · Token Checkup

粘贴任意 JWT，即时生成体检报告：声明逐条翻成中文白话、可视化 token 生命周期时间轴、安全体检清单——全部在浏览器本地解析。

## 解决什么问题？

JWT 是一串不透明的 `eyJhbGci...`。想回答几个最基本的问题——*过期没有？里面装了什么？结构对不对？是不是藏着 alg=none？*——开发者通常要么把 token 粘到随机搜来的在线解码站（凭据直接送进别人服务器），要么对着 console 输出皱眉。

JWT 体检卡**全程在你浏览器里**解码（零网络请求），而且比普通解码器多走一步：每条声明翻成中文白话；把 token 生命周期（签发→生效→现在→过期）画成带实时倒计时的脉冲时间轴；再跑一轮规则体检——揪出 `alg=none`、空签名、缺 `exp`、`iat` 在未来、远程密钥指针（`jku`/`x5u`）、以及误塞进 payload 的敏感字段。

## 怎么用

1. 打开 `index.html`（双击即用，无需构建、无需服务器）。
2. 粘贴 JWT（自动剥离 `Bearer` 前缀；边粘贴边即时体检）。
3. 看徽章判定、时间轴、声明卡片和体检清单。
4. 一键复制解码后的 Header/Payload JSON；或点内置三枚样例（有效 / 已过期 / alg=none）看报告如何反应。

## 说明

- 本工具**不验证签名**——验签需要密钥。报告里明说了，不装懂。
- 时间戳容错：部分签发方会误用毫秒（>1e12），工具自动识别并换算。
- 单文件原生 HTML/CSS/JS，零依赖、零 CDN、零遥测，可离线使用。
