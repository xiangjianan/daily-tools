# SCALELENS · 音阶透镜

[English](README.md) | 简体中文

选一个根音，键盘立刻点亮成 12 种音阶/调式或 8 种和弦中的任意一种。点键能弹、一键整条试听，全半音结构、成员音名直接标在琴键上。所有计算与发声都在浏览器本地完成。

## 解决什么问题

乐理是看不见的：书上说「多利亚 = 大调降 3、降 7」，但你从没"看见"过它。市面上的在线钢琴是弹奏模拟器，乐理对照表是静态表格——SCALELENS 补上中间缺失的那块透镜：把任意音阶或和弦直接画在两个八度的键盘上，让它的形状变成可以看、可以听、可以戳的东西。

## 怎么用

1. 选「音阶/调式」或「和弦」，选根音（C–B），再选类型（大调、多利亚、布鲁斯、大七……）。
2. 键盘点亮：绿色键即当前音集成员，键上标注音名。
3. 点任意键试音；按「▶ 整条试听」从头到尾弹一遍音阶（和弦为齐奏）。
4. 键盘快捷键：`a w s e d f t g y h u j k` 从 C4 半音上行；`空格` 播放/停止整条。
5. 「复制音级」把例如 `F Blues (scale): F Ab Bb B C Eb` 复制到剪贴板。

## 技术说明

- 单文件 HTML + 原生 JS + CSS，零依赖、零网络请求，离线可用。
- 声音由 Web Audio API 即时合成（三角波 + 指数衰减包络），无采样文件。
- 钢琴用绝对定位 DOM 键渲染，Pointer 事件统一鼠标与触屏。
- 无账号、无追踪、数据不出设备。
