# BPDOT · 血压落点仪

[English](README.md) | 简体中文

**BPDOT** 把两个数字——收缩压和舒张压——瞬间变成经典血压分区图上的一个落点。滑动或输入，脉冲圆点即刻落到对应的色彩分区里：十字导引线、分级判定、平均动脉压（MAP）、脉压，以及你自己的历史读数留下的淡点趋势痕。

## 解决什么问题

大多数血压工具输出的是一张表格：一段区间、一个标签、一堆文字，数字依然是抽象的。BPDOT 把读数当作**坐标**：高压在横轴、低压在纵轴，今天的读数落在 120/80 绿线和 140/90 红线之间的哪个位置一目了然——最近 30 次读数的漂移轨迹也直接留在图上。

## 怎么用

1. 用滑杆、步进按钮或直接输入设置收缩压（高压）与舒张压（低压）。
2. 圆点落到地图上，读取所在分区、MAP（平均动脉压）与脉压。
3. 可选填心率，点「📌 记下这次读数」保存在本机，点「复制摘要」分享结果。
4. 高低压记反会自动对调并提示；越界输入会被收敛并给出友好提示。

## 功能

- 按 AHA 2017 区间着色，中国指南 140/90 诊断线以虚线标出
- Canvas 实时渲染：动画脉冲圆点、十字导引线、网格与参考线
- 本地历史（最近 30 条，`localStorage`），以淡点形式留在地图上形成趋势痕
- 一键复制摘要，旧浏览器有剪贴板降级方案
- 完全离线、零依赖、单 HTML 文件——数据不出浏览器

## 技术说明

- 单页 HTML5 + 原生 JS + CSS，零构建、零 CDN，双击文件即可使用
- 分区底图通过列扫描一次性预渲染并缓存到离屏画布
- 手机宽度自适应；滑杆对触屏友好（`touch-action: none`）
- 非医疗器械。分区边界参考 AHA 2017 分类，诊断请遵医嘱。
