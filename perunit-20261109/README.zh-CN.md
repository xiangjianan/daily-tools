# 划算秤 PerUnit — 单价归一比价器 ⚖️

货架价签从不统一：`500ml`、`1.5L`、`250ml×6`、`30枚`、`140g*10卷`……到底哪个便宜？**划算秤**逐行解析「名称 价格 数量+单位」，把所有规格归一到同一基准——**每 100g / 每 100ml / 每米 / 每件**——排好序，最划算的戴上皇冠。

## 解决什么问题

心算单价容易出错，尤其是多包装（`250ml×12`）、混合单位制（斤/两 vs kg，L vs ml）和按件计数的商品（鸡蛋、纸巾）。用表格算太重，划算秤是零负担的中间态：贴几行进去，答案立刻出来。

## 怎么用

1. 每行一条：`名称 价格 数量+单位`，如 `怡宝 3.5 1.5L`、`纯牛奶 42 250ml*12`。名称可省略；**行内第一个数字是价格**，**最后一个「数字+单位」是规格**。
2. 支持单位：`g/克/kg/千克/公斤/斤/两/磅/lb`、`ml/毫升/l/L/升`、`枚/片/张/包/卷/瓶/盒/袋…`、`m/米/cm/mm`。多包装写法：`250ml*12`、`140g*10卷`、`250g×2`（也认 `X`）。拉丁单位不区分大小写（`500ML` 可以）。
3. 结果按单位家族分组（质量/容积/长度/计数），从便宜到贵排序：最便宜戴皇冠，其余标「贵 X%」；底部一句话总结冠军和每件差价。
4. 「复制比价报告」导出纯文本榜单。所有解析与计算**全部在你的浏览器里完成**，不联网、不上传。

说明（诚实限制）：行内第一个数字一律当价格，名称里带数字会干扰解析——请价格在前；欧式小数逗号（`12,5`）不支持，避免与千分位歧义。

## 技术说明

单文件 HTML + 原生 JS + CSS，零构建、零依赖、离线可用（双击即开）。单位词典把所有单位统一映射到基准量（g/ml/cm/件），数量正则支持可选的多包装倍数。解析为纯函数，配有 49 条单元断言。
