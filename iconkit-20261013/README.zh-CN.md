# ICONKIT · 图标全家桶熔炉

[English](README.md) | 简体中文

纯浏览器本地运行的favicon 一键熔炉：拖入一张图——或者只打 1-2 个字选个底色——立刻熔出网站图标全家桶：`favicon.ico`（16/32/48 三尺寸手工打包进 ICO 容器）、九个尺寸的 PNG（16 → 512，含 `apple-touch-icon.png`）、ZIP 打包，以及可直接粘贴的 HTML `<link>` 引用码。实时预览图标在浏览器标签页、书签栏、手机主屏里的真实长相。

## 解决什么问题

好用的 favicon 生成器（favicon.io、RealFaviconGenerator……）都要求把图上传到别人的服务器、走五步流程、信任一个黑盒；手头没图的人更是直接被挡在门外。ICONKIT 把这两件事都反转了：数据永不出浏览器，而且两个键就能开炉。

## 怎么用

1. **选素材** — 「用图片」页：点击或拖入任意 PNG/JPG/SVG/WebP/GIF（自动居中裁方）。「打两个字」页：输入最多 2 个字符，选底色、调圆角；深浅底自动反色配黑/白字。
2. **实时看** — 预览舞台把图标渲染进仿浏览器标签页（亮/暗可切）、书签栏、iPhone 主屏圆角块，每次改动即时刷新。
3. **拿产物** — 下载 `favicon.ico`、下载全家桶 ZIP（ico + 9 张 PNG + `html-snippet.txt`），或直接复制 `<link>` 引用码粘进 `<head>`。

无需注册、无需上传、加载后零网络请求。双击 `index.html` 离线可用。

## 技术说明

- 单文件 HTML5 + 原生 JS + CSS，零依赖、零构建。
- `.ico` 容器在 JS 里逐字节手工组装（ICONDIR + ICONDIRENTRY，PNG-in-ICO 载荷）——魔数、目录项偏移、总长均经程序化校验。
- ZIP 同样手写：STORE 直存 + 表驱动 CRC32，本地头 + 中央目录 + EOCD，经 CRC 回读校验。
- 源画布归一到 512×512，各目标尺寸高质量降采样；`apple-touch-icon.png`（180）强制垫白底，因为 iOS 会把透明渲染成黑色。
- 忙时输入排队：渲染中途触发的新渲染会挂起并在空闲后自动重跑，任何按键都不会丢。
