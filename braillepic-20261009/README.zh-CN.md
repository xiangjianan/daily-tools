# BRAILLEPIC — 盲文点阵画：图片转 Unicode 盲文字符画

拖入、粘贴（Ctrl+V）或选择一张图片，还你一整面 **Unicode 盲文字符**。每个盲文字符自带 2×4 点阵，分辨率是经典 ASCII art 的 **8 倍**——而且产出就是普通文本，可以直接贴进 GitHub README、代码注释或聊天窗口。

## 解决什么问题？

ASCII 字符画一个字符只能画一个像素，塞进一条消息里就糊成一团。盲文字符每个编码 8 个像素（U+2800–U+28FF），用零头字符数保住真实细节。BRAILLEPIC 还治"灰阶糊成一片"的老毛病：内置**抖动**（拜尔有序抖动 / Floyd–Steinberg 误差扩散），配合亮度、对比、反相，深底截图也能出层次。

典型用途：README / 终端装饰、等宽字体签名、纯文本环境里的插画，或者纯粹拿截图玩。

## 怎么用

1. 双击打开 `index.html`（file:// 直接可用）。
2. 拖入图片、点击选择，或直接 **Ctrl+V** 粘贴截图。
3. 调宽度（30–180 字）、亮度、对比、抖动、反相——字符画实时重渲染。
4. 点 **复制字符画** 复制，或 **下载 .txt**（Ctrl+S）保存。

手边没图？点 **载入示例**，工具会程序化画一张月夜山景给你。

全部在你的浏览器本地完成——零网络请求、零上传。

## 技术说明

- 单 HTML 文件，零依赖零构建，原生 JS + CSS。
- 明度按 Rec. 709 加权；盲文点位遵循 Unicode 标准（dot 1–8 → U+2800 + 位掩码）。
- 拜尔 4×4 与 Floyd–Steinberg 抖动都作用在字符映射前的亚像素网格上；ASCII 模式按 10 级明度字符梯 ` .:-=+*#%@` 映射。
- 图片在 canvas 上按"每字符列 2 px"（盲文）降采样——480 px 源图瞬间渲出约 240 字宽。
- 剪贴板走异步 API，`file://` 下自动回退 `execCommand`。
