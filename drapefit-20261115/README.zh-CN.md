# DRAPEFIT · 窗帘裁布计算器 🪟

[English](README.md) | [简体中文](README.zh-CN.md)

把窗户变成一张精确窗帘采购单的单页计算器：用布总米数、每幅裁剪尺寸、打孔/挂钩数量，外加布卷排料图——全部在浏览器本地计算。

## 解决什么问题

网购窗帘全靠猜：客服问「150 门幅的布你要几米」，而这个答案取决于褶皱倍率、对开还是单开、顶部工艺、折边和拼缝。买少了帘子不够长，买多了白花钱。DRAPEFIT 把裁缝间的算术一次做完，还画出每一刀落在布卷的哪个位置。

## 怎么用

1. **量窗**：输入轨道覆盖宽度（cm）和帘长（cm），或点预设（落地 / 半帘 / 飘窗）。
2. **定风格**：选拌挂法（打孔 / 四爪钩 / 穿杆）、对开或单开、褶皱倍率（1.6–2.5×）、布料门幅（150 / 280 / 自定义）、底折边，选填布单价。
3. **看结果**：用布总米数、每幅裁剪尺寸、杆长建议、打孔数量与孔距（或挂钩数）、拼缝告警、参考总价。
4. **复制采购清单**发给裁缝或客服；页面也适合直接打印。

## 技术说明

- 单文件 `index.html`——原生 HTML/CSS/JS，零依赖、零网络请求、离线可用。
- 两张 SVG 示意图（褶皱立面图 + 布卷排料图）均为客户端实时生成；输入框与滑杆双向联动即时重绘。
- 算法：每片完成宽 = 杆长 × 倍率 ÷ 片数；每片幅数 = ⌈片宽 ÷ 门幅⌉；每幅裁长 = 帘长 + 顶部翻边 + 底折边；打孔数按行规取 16cm 左右孔距并强制奇数。
- 数据不上传——所有计算都留在你的浏览器标签页里。
