# TireFit · 换胎对照仪

输入当前轮胎和候选轮胎的规格，用同比例剖面图 + 双针速度表，把「直径差 / 速度表误差 / 离地间隙变化」画出来给你看。

## 解决什么问题

换不同尺寸的轮胎（比如 `205/55 R16` → `225/45 R17`）会改变滚动直径。速度表数的是车轮转数、按原厂胎标定——换大胎后表显偏慢、里程表少记；换小胎则相反。市面上的换胎计算器大多只给一串干巴巴的数字，你永远"看不见"差异有多大、指针会漂多远。

## 功能

- 解析两种规格写法（`205/55 R16`、`205/55R16`、带载重级别的 `205/55 R16 91V` 都行），算出外径、每公里转数、离地间隙变化。
- **同比例剖面双轮对比图**：带尺寸标注线，中间有 Δ 直径差标尺。
- **双针速度表**：青色实针 = 表显 100 km/h，琥珀色虚针 = 新胎下的实际车速。
- ±3% 法则判定徽章（轮拱间隙 / ABS·ESP / 年检的常用参考线）、40–120 km/h 误差对照表、一键复制体检报告。
- 内置常用换胎组合样例、A⇄B 交换按钮，空输入/非法输入有友好提示。

## 怎么用

浏览器打开 `index.html` 即可。输入两个规格，或点样例按钮；每次按键即时出结果，点「复制体检报告」拿纯文本总结。

## 技术说明

单文件 HTML + 原生 JS + 内联 SVG。全部计算在本地完成（外径 = 轮毂×25.4 + 胎宽×扁平比×2），无网络请求、无统计埋点、数据不出浏览器。已对手算参考值验证（`205/55 R16` = 631.9 mm、`225/45 R17` = 634.3 mm、Δ +0.4%）。

## 局限

±3% 只是经验法则不是法规标准，各地规定不同；载重级别 / 速度级别 / 轮辋宽度匹配不在本工具范围内。结果用于快速参考，不构成改装合规保证。
