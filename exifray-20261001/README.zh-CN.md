# ExifRay — 照片隐私X光机

[English](README.md) | 简体中文

**ExifRay** 是一个单文件、零依赖的网页小工具：照出照片偷偷告诉别人的秘密，并一键给你一份干净副本。

## 问题

每张照片都可能带着元数据：精确的 GPS 坐标、手机型号、设备序列号、精确到秒的时间戳、后期软件痕迹。原样发出去，等于把家门钥匙一起发了。现有的 EXIF 查看器只停在「展示字段」——不告诉你哪些真正要命，也不帮你解决。

## 功能

- **拖拽 / 粘贴 / 选择** JPEG 或 PNG——全部在**浏览器本地**解析，照片永不离开设备。
- **隐私体检报告（0–100 泄露指数）**：精确定位、设备序列号、机主信息、精确时间、处理软件、内嵌缩略图、XMP/Photoshop 段、PNG 文本块，按严重度分色。
- **说人话的泄露卡片**——每一条都解释「为什么要紧」，而不只是罗列字段。
- **完整元数据表**——EXIF IFD0 / 拍摄参数 / GPS 三组（同时支持小端与大端 TIFF），PNG tEXt/iTXt/zTXt/eXIf/tIME 块。
- **一键生成清洁版**——经画布重编码只保留像素（JPEG 品质 92%，PNG 无损），随后**复检结果并自证：0 条元数据字段**。

## 怎么用

1. 用现代浏览器打开 `index.html`（双击即用，无需服务器）。
2. 拖入照片、粘贴截图，或点「载入一张泄密示例照」体验内置示例。
3. 看完体检报告，点「生成并复检清洁版」下载即可。

## 技术说明

- 单个 HTML 文件，原生 JS，零构建、零 CDN，`file://` 离线可用。
- 手写 JPEG 段遍历器、TIFF/IFD 解析器（大小端都支持）与 PNG 块解析器，不用任何库。
- 示例照片由 PIL 离线生成、base64 内嵌，演示完全离线可用。
- 测试套件中解析字段与独立的 Python/PIL 实现交叉验证。
