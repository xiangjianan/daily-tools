# JSONDIFF · JSON 对比树

粘贴两份 JSON，一张红绿对比树即时长出：新增字段亮绿、删除字段标红、改值字段黄色并内联显示 old → new。每条变更都带 jq 风格路径，点击即复制。全部解析与对比在你的浏览器本地完成，数据不出机器。

## 解决什么问题

对比两份 JSON——部署前后的 API 响应、新旧两版配置、一次 schema 变更——通常要么在命令行里 `jq` 加 `diff` 拼管道，要么把数据贴进在线对比网站、让第三方经手你的数据。JSONDIFF 一并替换掉这两条路：做的是理解嵌套、数组和类型变化的结构化对比（不是逐行文本对比），渲染成带标注的树，全程纯客户端。敏感数据永远不离开这个标签页。

## 怎么用

1. 把旧 JSON 粘进 **A（旧）**、新 JSON 粘进 **B（新）**——输入即对比，树和变更计数实时刷新；也可以把 `.json` 文件直接拖到任意一侧。
2. 读**对比树**：绿行是新增，红色删除线行是删除，黄行是改值（显示 `old → new`，类型本身变了会挂徽章，比如 number → string）。
3. 切到**变更清单**页，每条变更平铺成表，附 jq 风格路径（`$.users[1].roles[0]`）——点路径即复制，也可一键把整表复制成 Markdown。
4. **左右互换**翻转 A/B 看反向差异；**清空**重置。数组按索引逐项对位，长度变化会单独给一条「数组长度 N → M」记录。

## 技术说明

- 单文件 HTML + 原生 JS + CSS，零依赖、零构建，`file://` 双击即用。
- 纯函数内核：`tryParse`（解析报错在引擎给出 position 时附行列提示）、`typeOf`、`joinPath`（合法标识符键走点号、其余走方括号），以及 `diff`——单次递归遍历产出变更清单；树渲染消费同一份清单，两个视图永远一致。
- 35 条单元断言验证：新增/删除/改值/类型变化/数组长度变化、键顺序无关、空容器、null 互换、特殊字符键。
- 超大结构有上限保护（树 2,500 节点、清单 600 行）并如实提示截断——清单在达上限前始终完整。
- 双栏响应式布局，窄屏自动堆叠，深色主题，适配刘海安全区。
