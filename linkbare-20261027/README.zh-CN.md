# LINKBARE · 链接拆解台

粘贴一条链接——或直接整段分享文案——立刻拆开看：每颗查询参数都被点名、解码、分类（点击归因 ID / UTM 统计 / 社交分享噪音），点 chip 决定去留，逐字节重建干净链接，一键复制。全程在浏览器本地完成。

## 解决什么问题

经 App、邮件、社交网络转发的链接普遍拖着一条追踪尾巴：`utm_*`、`gclid`、`fbclid`、`si`、`ref_src`……它们撑爆 URL 和二维码、泄露你从哪里看到这条内容、还让链接看起来不可信。现有的清理器多是监听剪贴板的浏览器扩展或桌面应用——LINKBARE 是零安装网页，而且**给你看它到底摘掉了什么**，而不是悄悄改写你的链接。

## 怎么用

1. 粘贴 URL——或整段分享文案，自动抽出其中的第一条链接；裸域名（`example.com/x`）自动补 `https://`。
2. 看解剖：协议、域名、路径逐段着色，每颗参数一枚 chip，按类别着色，解码值直接展示。
3. 点 chip 逐颗决定去留；「全部保留」「恢复默认」批量操作。
4. 复制干净链接，或复制为 Markdown 链接。

默认策略：点击归因 ID（红）与 UTM/统计参数（橙）默认移除；社交分享噪音（黄）默认移除、一键可赎回；**不在名单里的参数一律保留**——工具不动它叫不出名字的东西，链接永远打得开。

## 技术说明

- 单文件 HTML + 原生 JS + CSS，零依赖、零构建，`file://` 双击即用。
- URL 用手写正则解剖而非 `new URL()`，**编码逐字节保真**——只有被移除的段会消失。
- 追踪词表是保守的人工清单（精确键 + `utm_`/`mtm_`/`pk_` 前缀）；`from`/`source`/`ref` 这类歧义键刻意不收，避免误伤功能性参数。
- 非法百分号编码原样展示不抛错；重复键与空值全程保真往返。
- 不发任何网络请求，链接与剪贴板不出页面。
