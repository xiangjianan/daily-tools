# ShotFramer — 截图装裱机

拖入一张截图，出来一张能直接发的成品图：浏览器 / 手机 / 裸圆角相框，精选渐变背景，可倾斜加投影——像给画装裱一样，给截图装裱。

## 解决什么问题

原始截图直接发到社交媒体、文档或博客里总是显得扁平。shots.so 这类工具效果不错，但要把图片上传到别人的服务器。ShotFramer 的全部合成**都在你的浏览器本地完成**——像素不出机器。

## 怎么用

1. 把截图拖进预览区，或 `Ctrl/Cmd+V` 粘贴，或点「选图」挑文件，也可以先玩内置示例。
2. 选相框：**浏览器**（带红绿灯和地址栏）、**手机**（包边 + 打孔摄像头）、**裸圆角**。
3. 选 8 种背景之一（7 组精选渐变或透明底）。
4. 微调倾斜（−10°…10°）、留白、圆角。
5. 「下载 PNG」（2× 分辨率）或「复制」直接进剪贴板。

## 技术说明

- 单 HTML 文件，零依赖、零构建，`file://` 双击即用，可离线。
- 全部合成在一个 `<canvas>` 上：程序化绘制相框（浏览器 chrome 含三色圆点 + 地址栏胶囊、手机包边含打孔摄像头）、投影、旋转包围盒计算、圆角裁剪。
- 源图先按最长边 1600px 缩放再合成，防止超大图撑爆内存；导出固定 2× 分辨率。
- 剪贴板导出走异步 Clipboard API，不支持时优雅降级为提示。
