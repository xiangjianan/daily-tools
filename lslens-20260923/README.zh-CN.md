# 🔍 LSLENS

**粘贴 `ls -l` 输出，即时得到可视化权限矩阵 + 安全体检。全程浏览器本地完成。**

**在线使用：** https://xiangjianan.github.io/daily-tools/lslens-20260923//

## 解决什么问题

开发者每天都在看 `ls -l`，但几乎没人真正「读」过它。`rwsr-xr-x` 危险吗？`drwxrwxrwx` 呢？`id_rsa` 上挂着 `rw-r-----` 呢？权限串是个 9 位密码谜题，大多数人只是瞟一眼——而真正危险的东西（世界可写脚本、setuid 二进制、组可读的私钥）就藏在每一份目录列表里。

## 它做什么

粘贴 `ls -l`、`ls -la` 或 `ls -lah`（Linux/macOS 均可）的输出，LSLENS 即刻：

- **给每个文件拍 X 光**：渲染成彩色芯片矩阵——青色 `r`、琥珀 `w`、品红 `x`、紫色 `s`、橙色 `t`——权限形状一眼可见
- **跑一遍安全体检**，标出：
  - 🚩 世界可写文件/目录
  - 🚩 setuid 可执行文件（以属主权限运行）
  - 🚩 组/其他人可读的私钥与机密文件（`.pem`、`.key`、`id_rsa`、`.env`…）
  - ⚠️ setgid、大写 `S`/`T` 错误（特殊位却没配执行位）
  - 带 sticky 位的世界可写目录（`/tmp` 模式）只做提示不报警——那是公认的正常形态
- **用大白话解释每一行**——点击任意行查看「属主：读、写 · 组：读 · 其他人：无权限」，附八进制模式和每条问题的可复制 `chmod` 修复命令
- **如实报告解析不了的行**——格式不对的行计入 skipped，绝不瞎猜

底部的 **chmod 搭建器**反着用：点击权限位（含 setuid/setgid/sticky），即时得到八进制、`ls -l` 字符串、数字与符号两种 `chmod` 命令。

## 怎么用

1. 打开[页面](https://xiangjianan.github.io/daily-tools/lslens-20260923//)
2. 在终端跑 `ls -l`（或 `ls -la` / `ls -lah`），复制输出，粘贴进来
3. 看芯片图，点红旗行看详情和修复命令，**Copy report** 导出 Markdown 表格

点 **Load sample** 可一键载入含典型风险案例的示例（setuid 脚本、世界可写文件、可读 `id_rsa`…）。

## 技术说明

- 单个 HTML 文件，零依赖、零构建、零网络请求——所有解析都在浏览器本地完成，不上传任何数据
- 离线可用：存下文件双击即用
- 兼容 Linux/macOS 的 `ls` 变体：`-h` 人类可读大小、软链接 `->` 目标、`Sep 23 10:12` 和 `Sep 23 2024` 两种日期格式
- 鼠标与触屏都支持，响应式适配手机宽度
