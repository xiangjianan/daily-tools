# STITCHMAP · 照片变十字绣图纸

把任意照片变成一张能照着绣的十字绣图纸：每个格子都匹配到**真实 DMC 绣线色号**（456 色色表），支持色块 / 符号 / 混合三种视图，并直接生成可以拿去买线的**配线清单**。

## 解决什么问题？

"我家猫的照片能绣成十字绣吗？"——现有的答案要么装 App、要么注册上传、要么导出带水印。STITCHMAP 用一屏搞定，全程在浏览器本地完成：图片不出你的电脑，而且给你的是绣线色号，不是"差不多"的颜色。

## 怎么用

1. 拖入 / 选择 / 粘贴（Ctrl+V）一张图，或点**试个示例图**。
2. 调参数：图纸宽度（30–180 格）、最多颜色（6–48 色）、绣布格数（11/14/16/18 ct）。
3. 切视图：**色块**看整体，**符号**方便数格子，**混合**适合照着绣。
4. 复制 DMC 配线清单，或把图纸下载成 PNG。

成品尺寸与用线支数随布格数实时换算（页面内展示了估算口径：8m 一支对折 2 股可用 4m，实际因松紧 ±30% 都正常）。

## 技术说明

- 盒式平均降采样到格子尺寸（跳过透明像素），再在 **CIELAB** 色彩空间把每格匹配到最近的 DMC 色。
- 只保留出现频率最高的 N 个线号，其余格子重映射到保留色板——保证配线清单与图纸逐格一致。
- 纯前端：单 HTML 文件，零依赖，零上传，`file://` 双击即用。

## 说明

- DMC 色值来自社区色表（nathantspencer/DMC-ColorCodes），为社区通用近似值，非官方分光读数。
- 透明像素跳过（不计入总针数与配线清单）。
