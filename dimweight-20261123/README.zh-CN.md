# DIMWEIGHT — 抛重预判台

寄快递之前，先算清楚你会**按多重计费**。输入箱子的长 × 宽 × 高和实重，DIMWEIGHT 即时算出体积重、计费重（两者取大、按 1kg 向上进位），还能反过来玩：给定一个计费重预算，告诉你预算内**最大能寄多大**——要么给最优正方体边长，要么保持你当前的长宽高比例算最大缩放。

## 解决什么问题

快递公司按 `max(实重, 体积重)` 计费，体积重 = 长宽高(cm)之积 ÷ 除数。多数人是在快递员拿出账单那一刻才知道自己寄的是「抛货」。DIMWEIGHT 把这条行业规则翻译成人人可用的交互：

- **单件即输即算** —— 长宽高一边敲，体积重 / 实重 / 计费重三格即时刷新，并提示这件是「体积主导的抛货」还是「实重主导」。
- **除数口径预设** —— 6000（主流快递）、8000（部分陆运）、12000（经济件）、5000（跨境/航空），切换后全页联动重算。
- **反推模式** —— 拖滑杆设定计费重预算，给出最优正方体边长（∛(预算×除数)），或保持当前比例的最大缩放系数。
- **多件拼单清单** —— 逐件加入列表，看每件和合计的计费重，一键复制纯文本清单（发群里 / 发给快递员）。
- **等比例箱体可视化** —— 边敲边重画的等轴测箱体：抛货染琥珀色、实重主导染蓝色，一眼看出「塞太松空气也在计费」。
- **友好单位** —— 尺寸支持 cm / 英寸，重量支持 kg / 斤，全部本地折算。

## 怎么用

1. 任意浏览器打开 `index.html`（双击即用，离线可用）。
2. 输入长、宽、高、实重，结果随输入即时更新。
3. 按承运商选择除数口径（不确定就保持默认 6000）。
4. 可选：点「反推最大尺寸」进入反推模式，拖预算滑杆看预算允许的最大箱子。
5. 可选：「加入拼单列表」累计多件，「复制拼单清单」导出可分享的文本。

## 技术说明

- 单文件自包含 `index.html` —— 原生 HTML/CSS/JS，零依赖、零网络请求、零构建。所有计算与渲染都在浏览器本地完成，数据不上传。
- 等轴测箱体为手写内联 SVG；反推用 `Math.cbrt` 立方根。
- 除数口径仅为常见参考值，各承运商有差异且会调整，页面如实标注，可横向对比。
- 计费口径：计费重 = max(实重, 体积重)，按 1kg 向上进位（国内快递通行口径；部分承运商续重按 0.5kg 进位，页面已注明）。
