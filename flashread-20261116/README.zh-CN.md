# 📽️ FLASHREAD — 速读放映机

把长文粘贴进来，像放映机一样逐块闪现播放——视线钉在同一个红色对焦点上，不用再逐行扫视。

## 解决什么问题

普通阅读有很大一部分时间花在眼球移动上：跳视、换行回扫、读岔了回头找，能吃掉三分之一以上的阅读时间。RSVP（快速串视呈现）把模型反过来——不是眼睛扫过文字，而是文字闪过眼睛。每一块都在屏幕同一位置闪现，**最佳识别点（ORP）**用红色高亮钉在同一条竖线上，视线原地不动就能读完。

## 怎么用

1. 粘贴文章（中文英文混排都行），或先塞一篇示例文章。
2. 点 **🎬 开始放映**——文字逐块闪现在屏幕中央，对焦字红色高亮。
3. 随时调整：
   - **速度滑杆**——120–900 字·词/分钟
   - **每组字数**——1–4 字一组（中文切片，英文按词）
   - **点击屏幕 / `空格`** 播放暂停；`←` `→` 前后一块；`R` 重来
4. 胶片进度条可以点按拖动跳转任意位置，剩余时间实时更新。
5. 放完出结账卡：总块数、实际用时、平均速率。

## 一些较真的细节

- **标点感知停顿**——逗号约 1.5×、句末约 2.2× 多留时间，播放有呼吸感而不是匀速念经。
- **真·定宽对焦对齐**——40/20/40 三栏网格，红字永远在同一条竖线上，不管当前块多长。
- **中英双语分词**——英文按空白切词、尾部标点剥成独立停顿块；中文先剥标点、再把剩余文字按定长切片（不依赖词典）。
- **诚实处理边界**——空输入给友好提示；`42.5%` 保持完整一块；引号破折号变成短停顿块而不是黏在词上。

## 技术说明

- 单文件 `index.html`，原生 HTML/CSS/JS，零依赖零构建——双击即用。
- 全部分词与播放都在浏览器本地完成（`requestAnimationFrame` 计时），数据零上传。
- 鼠标触屏通吃，手机宽度响应式，暗色影院主题。
