# TALKTIME · 口播秒表

粘贴口播 / 短视频脚本，立刻知道**念出来要多久**——段落时间条、目标时长判定、"删掉第几段能压线"的具体建议、按所选语速模拟试读。全程浏览器本地计算。

## 解决什么问题

写稿的人都在猜时长：稿子写完觉得刚好，配音一念超了四十秒，只能含泪删。现有工具只给字数，没人告诉你**该删哪一段**、**这个语速念起来什么感觉**。

## 怎么用

1. 粘贴脚本（空行分段）。
2. 看总时长（mm:ss）和构成：中文字数、英文/数字词数、停顿点。
3. 选语速档（慢速 / 常速 / 快节奏）和目标时长（或自定义秒数）。
4. 拿到判定：超时 / 刚刚好 / 还有富余——附贪心删减建议（"删第 1 段（约 0:18）→ 0:47 ✓"）。
5. 点时间条看单段时长；按 ▶ 模拟试读，句子按真实节奏逐句高亮；一键复制文字版摘要。

## 估算模型（诚实声明）

- 常速基准：**中文 240 字/分**、**英文 165 词/分**（数字、URL 按词计）。
- 停顿：每个句末终止符（`。！？…；.!;`）+0.35s，段与段之间 +0.25s。
- 这是估算不是提词器，实际语速因人而异；全部常数在页脚和源码里公开可见。

## 技术说明

单文件 `index.html`，零构建、零依赖、零网络请求。手写分句器用对称正则类（终止符集合与其补集同源生成，避免贪婪/排除不对称）。离线可用，鼠标触屏皆宜，深色主题。
