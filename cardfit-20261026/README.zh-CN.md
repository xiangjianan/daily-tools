# CARDFIT · 分享卡片试衣镜

粘贴网页 HTML（整页或仅 `<head>`），立刻看到这条链接分享到 **Google 搜索、X/Twitter、Slack、Telegram、微信** 时各是什么样子——五面试衣镜卡片实时刷新，附加权 10 项体检清单，一键生成补齐缺项的 `<head>` 片段。全部在浏览器本地解析，零上传。

在线使用：<https://xiangjianan.github.io/daily-tools/cardfit-20261026/>

## 解决什么问题

OG 标签不分享出去永远看不见——等你按下「发送」，光秃秃的链接、裁烂的图、缺失的缩略图已经到了读者眼前。现有预览工具（如 metatags.io）由服务器抓取你的 URL：staging 站、本地开发页、带鉴权的页面全都抓不到，还会把未发布的链接交给第三方。

CardFit 反过来：你粘贴 HTML，它本地解析，全程零网络请求。

## 怎么用

1. 把页面 HTML 粘进编辑器（整页或仅 `<head>` 都行），五面试衣镜随输入即时刷新。
2. 可选：拖一张图进来（或点拖放区）。它充当 `og:image` 替身，让你看清 X（1.91:1）与微信（1:1）各怎么裁——文件不离开浏览器。
3. 看体检清单：缺失/超长标签、`og:image` 相对路径等分享杀手用白话逐条标注，附加权就绪度评分。
4. 点「生成补齐缺项的 `<head>` 片段」——只补你缺的标签，必须自己填的地方留占位。复制粘贴进页面即可。

内置两个一键示例：「一篇博客」（满分配置）和「一份翻车的」（典型错误：标题超长、图片相对路径、缺描述）。

## 检查什么

- `<title>` 有无、`og:title` 回退、Google 约 60 字截断
- `description` / `og:description`、约 155 字截断
- `og:image` 有无 + 绝对地址检查（相对路径外部平台抓不到）
- `og:url`、`og:site_name`、`twitter:card`（大图卡需显式声明）
- 缺失标签在每个平台卡片的退化各不相同——模拟卡片如实演给你看

## 技术说明

- 单个自包含 HTML 文件，零构建、零依赖、零网络请求
- 用 `DOMParser` 解析；模拟卡片为各平台分享 UI 的纯 HTML/CSS 复刻
- 图片经 `FileReader` 转为 data URL，仅存内存
- 鼠标触屏双支持，响应式适配手机
