# FontPeek · 字体清点镜

**每台电脑都悄悄装着上百款字体，却没人知道它们是谁。FontPeek 一眼清点本机字体，点选即组 `font-family` 栈，全程本地。**

在线使用：<https://xiangjianan.github.io/daily-tools/fontpeek-20261024/>

## 解决什么问题

给 CSS 项目挑字体全靠猜：你的机器里藏着一套「系统字体 + 中文字体」的私人藏书，但系统没有提供任何界面告诉你装了什么。设计师开个记事本「试一下」，开发者照抄一堆本机根本没装的 `font-family`。

## 它做什么

- **打开即清点**：载入瞬间用 canvas 文字宽度对比法探测约 140 个候选字体（web-safe 经典、macOS / Windows / Linux 系统字体、开发者流行款、30+ 款中文字体），已安装的以卡片点亮，且**用它自己渲染自己**。
- **活字样板**：示例文字随手改、字号滑杆随手拖，所有卡片实时刷新——用你自己的文案试字体，而不是 Lorem ipsum。
- **筛选与搜索**：分类胶囊（无衬线 / 衬线 / 等宽 / 中文 / 手写·展示）+ 名称搜索。
- **点选组栈**：点卡片加入选区，底部浮条即时组出 `font-family:` CSS 并带实时预览，一键复制 CSS 或纯名称列表。

## 怎么用

1. 打开页面，探测即刻完成（通常 < 100 毫秒）。
2. 改成自己的示例文字，调字号。
3. 按分类筛选或按名称搜索。
4. 点选卡片组栈，点「复制 font-family CSS」。

## 技术说明

- 单文件 HTML + 原生 JS + CSS，零构建、零 CDN、零网络请求。
- 探测原理：用一条中英混排探针串在 72px 下分别测 `"<字体名>", <基线>` 与三种基线（`monospace` / `serif` / `sans-serif`）的宽度，任一基线宽度差 > 1px 即判定已安装。同名变体可能合并（宽度探测法的已知局限）。
- 全程浏览器本地运行，不上传、不存储、不采集任何信息。
