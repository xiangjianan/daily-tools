# DOUGHMATH · 面团配比秤

输入**几个面团 × 每个多重**，即出全配方克数表——水合率滑杆调软硬，即发酵母/酸面团双模式，再选一个出炉时间，自动倒推出从喂酵到出炉的完整时刻表。

**在线使用：** https://xiangjianan.github.io/daily-tools/doughmath-20261113/

## 解决什么问题

网上的面包配方都是固定份数，换成你的烤盘、你的饭量就得手算烘焙百分比；酸面团更麻烦——酵种自带面粉和水，必须从"另加"里扣掉。DOUGHMATH 替你记账：选定球数和球重，所有材料实时重算，酵种按自身水合率拆回面粉与水，加减账目守恒。

## 怎么用

1. 选发酵方式：**即发酵母** 或 **酸面团**（酵种占面粉百分比 + 酵种自身水合率）。
2. 设定**面团数量**和**每个克重**（比如披萨 4 × 250g）。
3. 拖**水合率**滑杆——58% 贝果硬度到 80% 高水合恰巴塔——再调盐量。
4. 选**出炉时间**和发酵总时长，时刻表从烤箱倒着排：喂起子 → 混合自解 → 折叠 → 整形 → 冷藏松弛 → 预热 → 烘烤，跨夜自动处理。
5. 点**复制**拿到纯文本配方 + 时间线便签，直接贴进备忘录。

## 技术说明

- 全程烘焙百分比：面粉 = 100%，其余按占面粉比例计；成分堆叠条显示各材料占面团总重的份额。
- 酵种按自身水合率分解回面粉和水，"另加"行就是你实际要称的量——总量守恒（单测验证）。
- 边界全钳制：1–24 个、30–600g、水合 50–90%；非法或空输入回落安全默认值。
- 单文件 `index.html`，约 460 行，原生 JS，零依赖、零网络请求——数据全程留在本机。
