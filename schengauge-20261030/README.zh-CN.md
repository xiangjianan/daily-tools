# SCHENGAUGE — 申根 90/180 天窗仪

把你的申根行程（出入境日期）贴进去，看滚动 180 天窗口随时间呼吸：顶部预算曲线逐天显示 90 天配额的实时用量，历史行程自动做超留体检，规划器即时判定未来行程是否可行——不可行时还会告诉你该日最多能待几天。全程浏览器本地运行。

## 解决什么问题

申根 90/180 规则以反直觉著称：不是「每半年 90 天」，而是**任意滚动 180 天窗口内停留不超过 90 天**。多数在线计算器把这条规则藏进「输日期 → 出数字」的表单里，旅行者无法建立「旧行程滑出窗口、额度慢慢回血」的直觉。

## 怎么用

1. **添加行程** — 选入境/离境日期点 ＋（首尾两天都算），或点「载入示例」直接看效果。
2. **读仪表盘** — 四张状态卡：当前窗口已用天数（截至今天）、还剩几天、下一次回血日期、超留预警。
3. **探索时间带** — 顶部曲线是每天的窗口用量，琥珀色虚线是 90 天红线，底部色带是停留段（实心=已发生，虚线=计划中）。悬停/点按任意日期看精确计数。
4. **规划** — 选未来入境日和停留天数，判定即时出现（✓ 可行 / ✗ 顶破红线），附该日最大可停留天数、以及最早哪天起能待满你想待的天数。
5. **复制** — 一键导出纯文本体检摘要。

## 技术说明

- 单 HTML 文件，零依赖、零构建，`file://` 双击即用。
- 日期运算全部基于「当地正午」天序号（免 DST 干扰）；窗口逐天扫描：`used(d)` 统计 `[d−179, d]` 内的停留天数；规划器逐天模拟累加，首个违约日即停。
- 超留体检扫描**每一个历史日**（峰值可能出现在行程中段，而非行程末尾）。
- 行程只存在页面内存里，不落盘、不上传。
