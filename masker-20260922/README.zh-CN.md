# 🛡 MASKER — 粘贴即脱敏的日志清洗器

**粘贴日志 / JSON / CSV，即时得到一份"格式保形"的脱敏孪生。** 邮箱、IP、UUID、Bearer token、手机号、卡号全部替换为同形态的确定性假值。100% 浏览器本地完成——数据从不离开你的机器。

**在线使用：** https://xiangjianan.github.io/daily-tools/masker-20260922//

## 解决什么问题

撞上一个诡异的 bug，想把日志贴进 GitHub issue——或者直接喂给 LLM。但日志里全是真实邮箱、内网 IP、API key 和会话 UUID。手动清洗太繁琐，于是多数人直接跳过，顺手就泄漏了。

## 怎么用

1. **随便粘贴**——右侧实时出现脱敏孪生，每一处替换都有彩色高亮。
2. **分类芯片显示检出结果**——邮箱、IPv4、UUID、Bearer token、hex/base64 token、手机号、卡号，各带计数，可逐类开关。
3. **同 seed → 同输出。** 替换值由种子决定：`user@x.com` 无论出现多少次、刷新多少遍，都变成同一个假值，日志里的交叉引用保持连贯。点 🎲 reroll 换一套全新假身份。
4. **一键复制或下载**脱敏结果；分享前可在本地展开映射对照表（原值 → 假值）核对。

## 为什么可信

- **格式保形**：假邮箱长得像邮箱，假 UUID 是合法 v4 UUID，假卡号通过 Luhn 校验，假 token 长度分毫不差。结构感知高亮把每一处命中内联标出。
- **刻意保守**：手机号必须带 `+` 国际区号；卡号必须过 Luhn（订单号、时间戳原样不动）；长 token 必须真的像 hex 或 base64。干净的结果会明说：*"未发现可识别的敏感模式"*。
- **三零承诺**：不上传、不要账号、无统计埋点、无构建步骤。就一个 HTML 文件——下载下来永久离线可用。

## 边界与实话

基于正则的检测只是助手，不是审计工具。自由文本里的人名、用户名不在范围内（极易误报）；发布前请通读一遍结果。不带 `+86`/`+1` 区号的手机号不会被捕获。

## 技术

单文件 HTML + 原生 JS + CSS，零依赖、零网络请求。确定性 PRNG（xmur3 + mulberry32），键为 `seed + 原始值`。检测走单遍优先级正则（邮箱 → UUID → bearer → 卡号 → IPv4 → 手机号 → hex → base64）。
