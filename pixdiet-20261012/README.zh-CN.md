# PIXDIET

English | [简体中文](README.zh-CN.md)

> 注：本文件为中文版说明，英文版见 [README.md](README.md)。

拖一张图进来，输入目标文件大小，PIXDIET 自动搜索出「刚好塞进目标」的压缩质量，并给你一张前后对比的减肥报告单。全程在浏览器标签页内完成，图片永远不上传。

**在线使用：** https://xiangjianan.github.io/daily-tools/pixdiet-20261012/

## 解决什么问题

大多数图片压缩工具把「搜索」丢给你：拖质量滑杆 → 导出 → 看大小 → 没达标 → 再拖……而那些「贴心」的在线工具还要你先把截图照片传到别人服务器上。

PIXDIET 把工作流反过来：你说的不是质量，而是**预算**（「博客配图 100KB 以内」「聊天软件 200KB 以内」）。工具对编码器质量参数做二分搜索（最多 8 轮、5% 粒度），找出能塞进预算的最高质量——一秒左右出结果，全程离线。

## 功能

- **目标大小模式** — 输数字、选 KB/MB，或直接点快捷档（50K/100K/200K/500K/1M）。自动二分质量，报告最终落在哪个质量值。
- **诚实失败** — 目标物理上达不到时（比如 4K 噪点图压到 5KB），明说，并导出最低质量的结果、建议缩小「最长边」；目标比原图还大时，直接按高保真输出，不假装「省了体积」。
- **手动模式** — 普通质量滑杆 + 实时大小读数，想完全掌控时用。
- **尺寸与格式** — 最长边限制（1920/1280/800 px）、WebP（压缩率最好、保透明）或 JPEG（兼容性最好、透明区域垫白底）。
- **减肥报告单** — 原图 → 结果大小、节省百分比条、输出尺寸，一键下载，文件名 `<原名>-diet.webp`。
- **边界情况** — 非图片文件 / 损坏字节给友好 toast；GIF 只取第一帧（chip 标注）；PNG→JPEG 提示透明变白底；计算忙碌期间的输入会排队而不是被丢掉。
- **100% 本地** — 纯前端、零依赖、零网络请求，双击 index.html 断网也能用。

## 怎么用

1. 打开页面（双击 index.html 即可，离线可用）。
2. 拖入图片（或点击选择），预览与信息 chip 即时出现。
3. 选模式：**目标大小**（默认）或 **手动质量**，按需设最长边和格式。
4. 看报告，点 **⬇ 保存减肥后的图**。

## 技术说明

单文件 HTML5 + 原生 JS（约 480 行）。零构建、零 CDN、无 cookie、无统计。压缩 = `canvas.drawImage` + `canvas.toBlob(mime, quality)`；目标大小搜索是对该质量参数的有界二分（8 轮、顺序执行控制内存），保留能通过的最高质量；下载用 `URL.createObjectURL`。
