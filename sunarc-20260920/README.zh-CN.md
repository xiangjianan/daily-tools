# ☀ SUNARC

**一眼看见太阳的弧线、黄金/蓝调时刻与全年日照——任意地点、任意日期，拖动太阳即可回放时间。**

**在线使用：** https://xiangjianan.github.io/daily-tools/sunarc-20260920//

## 解决什么问题

黄金时刻是摄影师、跑者、园艺爱好者最关心的时间，但大多数日出计算器把它埋在一堆数字表格里，太阳在天上到底怎么走始终不可见。

## 怎么用

1. 选一个城市预设（或直接输入任意经纬度）和日期。
2. 当天的太阳弧线即时呈现：日出、日落、太阳正午，以及带色块的**黄金时刻**（太阳高度 −4°～+6°）和**蓝调时刻**（−6°～−4°）。
3. **拖动太阳**沿弧线滑动，回放全天任意时刻的高度角。
4. 下方的**全年日照带状图**展示昼长如何随月份起伏，并标出今天。
5. 一键复制光报告或分享链接（URL 携带 `?lat=&lon=&date=`）。

极地场景如实呈现：北极圈内会直接给出*极昼*/*极夜*横幅，而不是给出错误时间。

## 技术说明

- 单文件 HTML + 原生 JS + Canvas。零构建、零 CDN、零联网——双击 `index.html` 离线即用。
- 太阳位置采用标准 NOAA 近似（赤纬 + 时角），按太阳时每 4 分钟采样；日出日落使用 −0.833°（含大气折射）阈值。
- 所有时间均为**当地太阳时**（12:00 = 太阳最高点），彻底绕开时区/夏令时的坑，这也正是摄影师的思维方式。
- 定位（如你允许）与全部计算都在浏览器本地完成，任何数据都不上传。
- 支持鼠标与触屏，手机宽度下响应式布局。
