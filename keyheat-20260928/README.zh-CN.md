# KEYHEAT

**粘贴文本 — 看你的键盘烧起来。**

KEYHEAT 把你粘贴的每个字符映射到实体 QWERTY 键盘上，实时渲染击键热力图，外加打字者从没见过的统计：总击键数、左右手配比、每根手指的负载，以及打完这段字你的手指要"跑"多远（按真实键位距离计算，1u = 19.05 毫米）。

## 解决什么问题

文本是抽象的——你看不出一份 40 行的配置文件其实是左小指的酷刑，也想不到打完一篇普通 README 手指要移动约 50 米。KEYHEAT 把日常打字看不见的人体工学变成看得见、也好玩的东西。

## 怎么用

1. 打开页面，粘贴任何东西：代码、文章、群聊记录。
2. 键盘即时升温——对数刻度的颜色，从冷灰到烧红。
3. 读 vitals 面板：击键数、手指行程、左右手配比（拇指不计入）、八指负载条。
4. **Copy stats** 导出 Markdown 报告；**Save PNG** 下载热力图卡片。

大写和上档符号会计一次额外的 Shift 击键（以及小指跑过去的路）。回车和 Tab 是真实击键。CJK/emoji 会诚实地计入"离版字符"，不会被悄悄丢掉。

## 技术说明

- 单文件 HTML，零依赖、零构建，双击离线可用。
- 全部计算在浏览器本地完成——你的文本永远不会离开这台设备。无统计、无上传、无账号。
- 行程模型：按打字顺序计算相邻键位中心点的欧氏距离，Shift 作为真实键位被"访问"。这是触打模型，不是录屏。
- 热力图用对数刻度，长文本下冷门键也能保持可见。

## 使用场景

- 对比布局/代码片段：哪个写法对小指更友好？
- 炫耀"我的 README 要跑 84 米"的趣味方式。
- 触打教学与人体工学演示。
