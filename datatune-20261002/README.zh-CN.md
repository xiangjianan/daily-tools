# DataTune — 数据旋律机

[English](README.md) | 简体中文

**DataTune** 是一个单文件、零依赖的网页小工具：把任意一列数字变成音乐。粘贴数据、点播放，用耳朵「听」服务器负载、体重记录、股票收盘价——异常值会变成你绝对错不过的明亮高音。

## 解决什么问题

肉眼扫一长列数字找异常又慢又累，趋势藏数字墙里。但人耳是天生的异常检测器：一段旋律里混进一个突兀的音高，零努力就能瞬间察觉。数据可听化（sonification）在科研领域用了几十年，却几乎没有一个日常工具能让你「粘贴数字、按下播放」就这么简单。

## 功能

- **随便粘**——CSV 列、日志、监控指标导出，任何文本里的数字都会被自动抽取（逗号 / 空格 / 换行 / 表格行都行）。
- **即点即播**——数值归一化后映射到大调五声音阶，Web Audio API 本地合成，数据不出浏览器。
- **异常值听得见**——|z| > 2 的点整体升一个八度，在钢琴卷帘里标成琥珀色，听觉 + 视觉双通道报警。
- **钢琴卷帘可视化**——音符随音频时钟实时落下，与声音零漂移；奏过的音符在击弦线上方淡出。
- **4 种音阶**（大调五声 / 小调五声 / 日式都节 / 半音阶）× **3 种音色**（正弦 / 三角 / 芯片方波）× 速度（50–240 BPM）× 移调（±12 半音）。
- **一键导出 WAV**——`OfflineAudioContext` 离线渲染，纯 JS 编码 16-bit PCM，直接下载文件。

## 怎么用

1. 浏览器打开 `index.html`（双击即用，无需服务器、无需联网）。
2. 粘贴数字（或点「载入示例：服务器 CPU 负载」——里面藏了一根毛刺）。
3. 按「▶ 播放」，留意那颗琥珀色音符；调调音阶和速度，满意后「⬇ 导出 WAV」保存。

## 技术说明

- 单 HTML 文件、原生 JS、零构建、零 CDN，`file://` 离线可用。
- 手写 WAV 编码器（RIFF 头 + 16-bit PCM）与 z-score 异常检测——不引任何库。
- 调度基于 `AudioContext` 的采样级时间戳，可视化读同一时钟，画面与声音永不脱节。
- 长序列上限 512 个音符，超出时统计栏会明确提示截断。
- AudioContext 在首次用户手势时才创建，天然兼容移动端自动播放策略。
