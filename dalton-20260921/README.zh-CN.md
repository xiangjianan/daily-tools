# DALTON.

**用色盲的眼睛看你的设计——拖入图片，即时对比，一键导出。全程本地处理。**

DALTON 是一个单文件、零依赖的网页小工具，模拟色觉障碍（CVD）人群眼中的图片、图表和 UI 配色。

## 解决什么问题

大约 **8% 的男性和 0.5% 的女性**存在不同程度的色盲，但大多数仪表盘、图表和状态指示仍然建立在红绿配对上——对他们来说这些颜色难以区分。现有的色盲模拟器要么是要把图片上传到服务器的在线服务，要么是笨重的库。缺一个快、私密、粘贴即看的答案。

## 怎么用

1. **拖入 / 粘贴 / 选择**任意图片（PNG · JPG · WebP），或点 **Try demo image** 看一张程序生成的、带经典红绿踩雷配色的仪表盘示例。
2. 选择视觉类型——**绿色盲（Deuteranopia）、红色盲（Protanopia）、蓝黄色盲（Tritanopia）、全色盲（Achromatopsia）**，三种异常三色视（*-anomaly），或正常视觉基线——再用**严重度滑杆**在 0%–100% 之间连续调节。
3. 与原图左右对比，满意后**下载**模拟后的 PNG。

## 差异化在哪

- **严重度连续可调**，不是只有开/关的二色视——异常三色视（最常见的一类）本质是*光谱*，很少有单文件工具能让你拖着扫。
- 支持**剪贴板粘贴**（`Ctrl/Cmd+V`）——截图一张图表，粘贴，立刻判断。
- **100% 本地**：每个像素都在你的浏览器里完成变换——在**线性 RGB** 空间应用 Viénot/Brettel 二色视矩阵（带完整的 sRGB gamma 往返）。不上传、不要账号、无遥测、零网络请求。
- 一个 HTML 文件，双击即用，离线可用，鼠标 + 触屏，适配手机宽度。

## 精度说明

二色视模拟采用可访问性研究界广泛使用的 Viénot/Brettel 方法；异常三色视的严重度用向对应二色视响应插值来近似。个体色觉差异很大——请把它当作设计辅助，而不是医学模拟。

## 技术

- 原生 HTML + CSS + JS，单文件（约 560 行），零构建、零 CDN
- Canvas 像素处理，长边 1400px 封顶，保证即时响应
- 内联 SVG favicon；深色主题
