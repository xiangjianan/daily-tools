# MRZLENS — 证件机读区解码台

把护照或证件照片底部的两三行机读码（MRZ）粘贴进来，立刻得到一份隐私优先的本地解码：逐字段解析、每个校验位逐字符对账、有效期体检。全程在浏览器本地完成，证件数据不出这台设备。

## 解决什么问题？

OCR 类 App 和来路不明的网站会很乐意让你上传护照照片。可很多时候你只是想知道「这两行到底写了什么、对不对得上」——为此把证件交给第三方既没必要也有风险。MRZLENS 在离线状态下给你全部答案：字段解码（姓名、证件号、国籍、日期、性别、个人编号）、**7-3-1 校验位审计**（逐字符展示值 × 权重 × 乘积）、有效期体检（已过期 / 不足 90 天 / 不足 180 天）、以及校验不符时的 OCR 混淆提示（O↔0、I↔1、S↔5、B↔8、Z↔2）。

## 怎么用

1. 打开页面（`file://` 双击即用，无需服务器、无需联网）。
2. 把证件上的机读码粘进输入框（小写、空格、分隔符会自动清洗）。
3. 或点一个示例：有效护照 / 临近过期护照 / 校验位被篡改 / TD1 身份证 / TD2 签证。示例都是运行时用真实算法现算校验位生成的，永远能通过自检。
4. 看判定条，然后细读三块输出：
   - **校验覆盖地图**——每个 MRZ 字符按「它参与哪道校验」着色；点任意字符，高亮它参与的审计行；点审计行，再回到地图上闪亮对应校验位。
   - **字段卡**——解码值 + 逐字段校验状态 + 日期推断。
   - **审计表**——每个校验位一行：字符 × 权重（7/3/1）逐格展示、加权和、取模、期望值 vs 机读码实写值。
5. 一键复制 Markdown 报告。

支持格式：**TD3**（护照，2 行 × 44）、**TD2**（签证，2 行 × 36）、**TD1**（身份证/居留卡，3 行 × 30），含 TD1 长证件号延伸进可选项的扩展形态。

## 技术说明

- 单文件 HTML，零依赖、零构建、离线可用。
- 校验位算法：字符值（数字=本身，A=10…Z=35，`<`=0）× 权重 7/3/1 循环，求和取模 10；综合校验按 ICAO 9303 规定的字段区间拼接后连续加权。
- 出生日期的世纪位是启发式推断（两位年份 ≤ 当前年份记 20xx，否则 19xx）——业界通用做法，页面与本文均已注明。
- 实现已对拍 [cheminfo/mrz](https://github.com/cheminfo/mrz) 测试套件中的 ICAO 9303 权威真值样本（57 条断言全过），并完成整页冒烟（零控制台报错）。
- 诚实边界：只验证机读区**内部自洽性**——无法鉴别证件真伪；对百岁上下的持证人，世纪推断存在天然歧义。
