# SHUPAI 竖排排版台

[English](README.md) | 简体中文

**SHUPAI** 是一个单屏竖排排版工具：粘贴横排中文，即刻排成右起、自上而下的竖排列 —— 古籍 / 请柬 / 书法格式 —— 支持句读朱点、三种纸色（宣纸白 / 绢黄 / 玄墨）、可选界栏，字号 / 列距 / 版高可调，一键导出逐字重绘的高清 PNG。

## 解决什么问题

竖排（CSS `writing-mode: vertical-rl`）浏览器原生支持，但几乎没有面向普通人的工具：要么得手写 HTML，要么没有干净的导出途径。SHUPAI 把它变成「粘贴 → 即看 → 下载」，全程在浏览器本地完成。典型场景：书法抄帖底稿、婚庆 / 节庆请柬、古诗卡片、竖排横幅、朋友圈图片文案。

## 怎么用

1. 在左侧文本框粘贴文字（空行分段）。
2. 调整字号、列距、版面高度；选择标点样式（原样 / 句读朱点 `︒` / 古式无标点）、纸色、界栏。
3. **下载 PNG** 在 2× canvas 上逐字自绘（非截图）；**复制文本** 把按列对齐的竖排纯文本复制到剪贴板。

边界处理：空输入显示友好占位并拦截导出；避头尾（标点不落列首，自动并回上一列）；多段之间自动空一列；英文 / 数字直立逐字排并给出明确提示。

## 技术说明

- 单文件 `index.html`，原生 JS + CSS，零依赖、零网络请求，全部本地处理（隐私优先）。
- 预览用真实 CSS `vertical-rl`；PNG 导出基于同一套切列数据在 canvas 重绘，所见即所得。
- 列模型：`buildCols(text, perCol)` → 段落列数组，含避头尾回拉，预览 / 导出 / 复制三处共用。
- 控制台运行 `#selftest()` 可执行 8 条核心断言（切列、避头尾、分段、字符守恒、标点映射）。
