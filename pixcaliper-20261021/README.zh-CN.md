# PixCaliper · 像素卡尺

粘贴截图即量的像素卡尺：8× 放大镜带实时取色，点两下画一把卡尺出距离/位移/角度，不限数量的测量清单，一键复制文字报告、导出标注 PNG。全程浏览器本地运行——不上传、无账号、无服务器。

## 解决什么问题

前端和设计师盯设计稿或线上截图时，最常问的是"这两个元素到底差几个像素"。桌面像素测距尺又重又绑系统，为一次快速检查不值得开。

## 怎么用

1. 截图后直接 `Ctrl/⌘ + V` 粘贴，或拖拽图片进来、选择文件——也可以点 **示例截图** 载入演示图。
2. 鼠标移动即有 8× 放大镜，显示像素网格与实时色值。
3. 点一下定起点，再点一下定终点：一把卡尺完成，附距离、Δx/Δy、角度与两端取色。按住 `Shift`（或勾选 **锁 45°**）吸附 45° 方向；`Esc` 取消未完成的起点。
4. 可连续画多把卡尺；点清单行高亮对应卡尺，✕ 删除。
5. **复制报告** 导出文字测量报告；**导出标注图** 下载带标注的 PNG。

## 技术说明

- 单文件 `index.html`，零依赖、零构建，`file://` 双击即用。
- 纯 Canvas 2D：一张离屏画布保存原始像素用于取色与放大，可见画布只叠绘制层。
- 点击坐标按 `canvas.width / rect.width` 归一化，任意 CSS 缩放（含手机触屏）下都准确。
- 图片输入支持剪贴板粘贴、拖拽、文件选择；object URL 解码后即回收。
- 标注图导出在离屏画布渲染，`canvas.toBlob` + object URL 触发下载。
