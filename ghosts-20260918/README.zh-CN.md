# 👻 GHOSTS — 不可见字符扫描器与驱魔器

**粘贴文本，看清每一个隐藏的 Unicode 幽灵，一键驱魔。**

🔗 **在线使用：** https://xiangjianan.github.io/daily-tools/ghosts-20260918//

## 它解决什么问题

不可见的 Unicode 字符无处不在——而且会造成真实破坏：

- **令牌与代码悄悄失效** —— 从 PDF、聊天窗口或幻灯片里复制一段字符串，一个零宽空格（`U+200B`）或软连字符（`U+00AD`）悄悄混了进来。肉眼看一模一样，运行必定出错。
- **Trojan Source 攻击** —— 双向控制符（`U+202E` 等）能让恶意代码*看起来*人畜无害，实际执行逻辑完全不同。（CVE-2021-42574）
- **同形异码字钓鱼** —— `pаypal.com` 里的 `а` 是西里尔字母，不是 PayPal 的 a。肉眼分不出，GHOSTS 分得出。
- **怪异排版字符** —— 不换行空格、细空格、全角空格会让解析器、搜索和分词器莫名其妙地坏掉。

最讨厌的是：这些字符*看不见*。看不见的东西没法修。

## 怎么用

1. **粘贴**任意文本（或拖入文件）—— **幽灵地图**会把每个隐藏字符渲染成内联的彩色芯片，与原文混排。
2. 悬停任意芯片，查看码位、字符名、类别与风险说明。
3. 查看**威胁报告**：按类别计数（零宽字符、双向控制符、怪空格、控制字符、同形异码字），并给出判定——`CLEAN` 干净 / `HAUNTED` 闹鬼 / `☠ DANGEROUS` 危险（双向攻击模式）。
4. 点下 **⚡ EXORCISE（驱魔）** —— 幽灵被删除、怪空格归一化、同形异码字换回 ASCII。一键复制或下载净化后的文本。

正常文本毫发无损：带音标字母、中文、破折号、弯引号只会以 `~` 标记温和提示，绝不会被自动删除。

内置四个**闹鬼样本**按钮——零上手成本，点一下就能体验。

## 技术说明

纯原生 HTML/CSS/JS 单文件实现。检测覆盖：

| 类别 | 示例 |
|---|---|
| 零宽字符 | `U+200B` `U+200C` `U+200D` `U+FEFF` `U+2060` |
| 双向控制符 / Trojan Source | `U+202A–202E` `U+2066–2069` |
| 怪空格 | NBSP、en/em/细/发丝空格、全角空格 |
| 控制字符 / 格式符 | C0 控制符、DEL、软连字符、变体选择符、标签字符 |
| 同形异码字 | 西里尔/希腊字母伪装、全角标点、智能引号、Unicode 破折号/减号 |
