# DUMAP · 磁盘空间树图（#66）

把 `du` 命令的文字输出粘贴进来，立刻得到一张可交互的方块树图（squarified treemap），外加「占地大户」排行。全部解析都在你的浏览器本地完成。

**在线使用：** https://xiangjianan.github.io/daily-tools/dumap-20261117/

## 解决什么问题

「磁盘空间被什么吃了」是服务器、开发机、CI 上的高频问题。常规答案是桌面工具（WinDirStat、GrandPerspective）或终端 UI（ncdu、gdu）——都得装到目标机器上，生产环境未必允许。但每台机器都能打印文本：`du -ab /path`。

DUMAP 把这段纯文本变成一眼可见的答案：SSH 里跑个 `du`，复制输出，粘进来。零安装、零上传、零代理。

## 怎么用

1. 在你的机器上跑 `du -ab /path 2>/dev/null`（字节级，推荐）或 `du -ah --max-depth=1 /path`（人类可读格式）。
2. 复制输出粘贴到文本框（或点「装载示例」先看看效果）。
3. 读树图：方块面积 ∝ 字节数。点击目录区域下钻，点面包屑返回。
4. 右侧看 **TOP 8 占地大户**，需要留档就「复制 Markdown 报告」或「导出 SVG」。

两种格式自动识别；识别不了的行会计数并跳过，不会让解析崩掉。

## 技术说明

- 单文件 HTML，零依赖、零构建，`file://` 双击即用。
- 布局采用 squarified treemap 算法（Bruls、Huizing & van Wijk），让矩形长宽比尽量接近 1。
- 一个关键正确性细节：`du` 报告的目录尺寸是**含子项的**（目录的数字已经包含下面所有东西）。DUMAP 会构建真实目录树并计算「自身字节 = 目录尺寸 − 直接子项之和」，面积绝不双重计数。粘贴的是部分输出时（如来自 `--max-depth`），没有自身行的目录由子项求和推导尺寸。
- 超过 3500 个方块的深层树会诚实截断，并在统计行给出提示。
- 支持鼠标和触屏，布局适配小屏手机。
- 隐私：解析、建树、渲染全部发生在浏览器里，没有任何上传——何况 `du` 输出本来就只有尺寸和路径。
