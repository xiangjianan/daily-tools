# PixelVault · 像素暗房

把一句话藏进图片像素的**最末一位**（LSB 隐写），再拖回来自动取出。全程在浏览器本地完成：无账号、无上传、零依赖。

**在线试玩**：<https://xiangjianan.github.io/daily-tools/pixelvault-20261108/>

## 解决什么问题

想在一张看起来人畜无害的照片里夹带一条小纸条；或者收到一张「PixelVault PNG」想知道里面说了什么。经典在线隐写网站要求你把图片（和秘密）上传到别人服务器——这本身就背叛了「秘密」二字。PixelVault 把整套暗房流程搬进你的浏览器标签页：像素从不离开页面。

## 怎么用

**藏信（🔒 藏信入图）：**
1. 拖入 / 点击 / 粘贴（Ctrl+V）任意图片——或点 🎲 生成一张黄昏示例底片。
2. 写下要藏的话，容量条实时显示还装得下多少（每像素 3 位，R/G/B 各一位）。
3. 点「藏入暗房」，下载成品 PNG。肉眼完全看不出差别——每通道亮度扰动 ≤ 1/255。
4. 可选 🔬「LSB 放大镜」：把每个最末位放大 255 倍，亲眼看见消息所在的雪花噪点。

**取信（🔍 取出密信）：** 把 PNG 拖回来即可。先验 `PVLT` 魔数与长度头再解码，干净图片会得到诚实的「这里什么都没有」，而不是一屏乱码；魔数只活下来一部分时，会提示图片多半经历过截图、缩放或压缩转发。

## 技术说明

- 单文件 `index.html`，零构建、零 CDN，首次加载后可离线使用。
- 编码格式：`PVLT` 魔数(4B) + 大端 u32 长度(4B) + UTF-8 内容，从左上角第一颗像素起按 R→G→B 顺序逐位写入最低位。不碰 Alpha 通道；带透明的图先铺白底保证位往返稳定。
- 容量 = ⌊(像素数 × 3 − 64) / 8⌋ 字节；640×400 能藏约 93.7 KB。
- 诚实的失败模式：`EMPTY`（魔数对但空信）、`BAD_LENGTH`、`BAD_UTF8`，以及 JPG 专属提示（有损压缩会重写全部最低位——消息必死）。暗房消息只活在原封不动的 PNG 里，聊天工具发图请选「原图 / 文件」。
- 验证：页面内嵌 codec 跑 13/13 node 对拍断言（中文/emoji、满容量边界、超容拒绝、单比特损坏、放大镜），外加浏览器全流程冒烟（藏入 → 以 File 回灌 → 取出逐字一致、干净图未取出、JPG 警示、超容锁按钮、放大镜渲染、360px 零溢出）。
