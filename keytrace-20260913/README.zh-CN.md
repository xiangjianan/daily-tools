# ⌨️ KEYTRACE

**看着你的密码在键盘上"散步"。** 粘贴任意密码或 PIN，KEYTRACE 会在一块发光的键盘上画出它真实的移动路径——让 `qwerty`、`1qaz2wsx`、`123456` 这类偷懒的"键盘走位"一眼现形。

🔗 **在线使用：** https://xiangjianan.github.io/daily-tools/keytrace-20260913//

## 解决什么问题

弱密码很少是随机的——它们是**路径**。手指在键盘上散步：`qwerty`、`asdf`、`1qaz2wsx`，破解字典最先尝试的就是这些模式。但普通的强度检测只给你一个抽象的"弱"标签，从不让你*看见*这条走位路线。

## KEYTRACE 做了什么

- 🎯 **实时轨迹**——每敲一个键，屏幕键盘上就点亮一节带编号的动画轨迹，输入/粘贴实时跟随
- 🔥 **热力图**——按得多的键从琥珀色烧到红色
- 🧭 **走位分（0–100）**——综合相邻步比例、最长直线连走、重复按键、内置经典走位库的启发式评分，四档判定：*键盘散步型 → 闲逛型 → 跳跃型 → 狂野飞人*
- 🙈 **防偷瞄模式**——一键模糊输入框内容，轨迹依然可见
- ⌨️ **点键盘直接输入**——屏幕键盘是真实输入设备（鼠标 + 触屏都能用）
- 📋 **复制报告**——一键导出判定结果文本
- 🌐 **中 / 英界面切换**

## 隐私

**100% 本地运行。** 单个 HTML 文件、零依赖、零网络请求、无统计埋点、不保存你的输入。密码永远不离开浏览器标签页——这正是这个工具存在的意义。

## 使用方法

1. 打开页面（离线可用，直接双击 `index.html` 即可）
2. 输入、粘贴，或直接点屏幕键盘
3. 查看判定与数据（相邻步、最长连走、变向次数、总路程……）
4. 需要的话一键复制报告

## 说明与局限

走位分是**用于安全意识的启发式评分，不是安全审计**。它衡量的是*键盘几何*而非信息熵——一个看起来随机的密码也可能因为复用、个人信息等原因而不安全。键盘外的字符（中文、emoji 等）会计数但不参与轨迹。

## 技术

单文件 `index.html`（约 560 行）：原生 HTML + CSS + JS，SVG 轨迹层，无构建、无 CDN，`file://` 直接可用。
