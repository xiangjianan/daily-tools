# 🌅 GOLDENTAB — 追光时刻表

一页回答「今天什么时候光线最好？」：选地点（定位 / 城市预设 / 手填经纬度）+ 日期，把一整天的光线做成**班次时刻表**——黄金时刻、蓝调时刻、白昼、航海晨昏、天文晨昏各班几点评上、几点评下，再配一条按太阳真实高度角着色的 24 小时天空色带。

## 解决什么问题

摄影师、跑者、追晚霞的人天天在问「今天黄金时段几点」，好用的答案要么是笨重的桌面软件（The Photographer's Ephemeris），要么是广告满天飞的网站。GOLDENTAB 用人人秒懂的「时刻表」隐喻即时给答案：每种光线是一班「列车」，有发车时间和到站时间。

## 怎么用

1. **地点**：点 📍 用 GPS 定位，点城市预设（三亚到漠河 11 城），或直接填经纬度（−90~90 / −180~180）。
2. **日期**：默认今天，可任选，「回到今天」一键弹回。
3. 看**状态卡**（此刻光型、太阳高度、方位、距下一次日出/日落的实时倒计时，每分钟自动刷新）、**指标行**（日出 / 日落 / 昼长 / 太阳正午）、**天空色带**（00:00→24:00 按太阳高度着色，日出日落虚线标尺 + 红色「此刻」线）、**班次表**（全部光型时段）。
4. **📋 复制报告**：一键把地点、日出日落与全部班次整理成纯文本进剪贴板。

判定口径：黄金时刻 = 太阳高度 −4°…+6°；蓝调时刻 = −6°…−4°；日出日落已含大气折射修正（−0.833°）。极昼/极夜不崩：缺的事件显示「—」，昼长一栏直接标注极昼/极夜。

## 技术说明

- 单文件 `index.html`，零依赖、零构建、离线可用——双击即开。
- 太阳位置用 NOAA 低精度算法（简化 Meeus）：黄经 → 赤经赤纬 → GMST 时角。全天每 2 分钟采样，阈值穿越点线性插值。
- 精度与 sunrise-sunset.org API 对表验证到分钟级：北京 2026-11-05 日出 06:47 / 日落 17:08 / 太阳正午 11:58 / 昼长 10 小时 21 分；三亚、漠河（夏至昼长 17 小时 02 分）全部吻合；78°N 极夜正确判出无日出。
- 全部计算在浏览器本地完成——零联网、零上传。时刻按设备所在时区显示。
- 鼠标触屏都好用，响应式下探到约 340 px。
