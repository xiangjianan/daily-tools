# RMBWORDS · 开票字码台

[English](README.md) | 简体中文

RMBWORDS 是人民币金额与财务大写之间的双向转换器——发票、支票、报销单上银行要求的正式大写
金额——外加一个手写大写金额的合规体检。

## 解决什么问题

发票上的大写金额是零容错字段：漏一个「零」银行就退票，而零的规则（段内零合并、段间补零、
收尾加「整」）是没人记得住的民间知识。RMBWORDS 把规则手册变成即时答案，并且做了现有换算工具
不做的事：把你手写的大写金额读回去、重新推导标准式、逐字比对，告诉你这写法交银行稳不稳。

## 怎么用

1. **金额 → 大写**：在第一个框输入 `1409.50` 或 `￥1,070,000.53`，即出标准财务大写，并配一
   把「数字直尺」——每 4 位一组（万/亿边界）、哪些零被合并、段间「零」从哪来，一眼看清。
2. **大写 → 数字 + 体检**：把手写大写粘进第二个框，得到解析出的数字外加「回程对拍」：工具把
   解析值重转标准大写并与你的写法逐字比对。完全一致 → 绿标；有出入 → 黄标并给出标准式与诊断
   （疑似漏零/字数不同）。
3. 每个框下面的一排示例点一下即载入（含央行文档里的经典示例金额）。
4. 复制按钮把结果放上剪贴板；非法输入给白话报错（最多两位小数、整数最长 16 位、认不得的字
   会在第几个字附近点名）。

## 技术说明

- 单文件 HTML + 原生 JS，零依赖、零网络请求，全部在浏览器本地完成。
- 标准式按银行/财务通行口径（央行「正确填写票据和结算凭证」规则）实现：段内零合并为一个
  零（3007 → 叁仟零柒）、段间补零（100010000 → 壹亿零壹万）、整段为零的段略去单位、无角无
  分收「整」、角为 0 分非 0 时元后补零（16409.02 → 壹万陆仟肆佰零玖元零贰分）。官方允许两
  种写法时输出较短的一种。
- 解析端宽容接受常见手写变体（「圆」代「元」、漏「整」、裸「伍角/伍分」），认不得或放错位置
  的字会指出第几个字附近，而不是静默失败。
- 金额范围：最多两位小数，整数部分最长 16 位。工具不验证大写与纸面小写金额是否相符——那
  一步请人工核对。
