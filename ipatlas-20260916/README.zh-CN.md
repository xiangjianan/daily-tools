# IPATLAS

粘贴一个 IPv4 地址或 CIDR 网段，立刻看到它的"地图"：这个网段有多大、边界在哪、以及它坐落在整个 IPv4 宇宙的什么位置。

**在线使用：** https://xiangjianan.github.io/daily-tools/ipatlas-20260916//

## 为什么做

CIDR 计算是看不见摸不着的。`10.0.0.0/8` 和 `172.16.0.0/12` 谁大？你办公室的那个 `/24` 在 43 亿个地址里到底住在哪？教科书给的是一张数字表，IPATLAS 把它变成可以指着的像素。

## 功能

- **网段地图** — 地址空间渲染成像素网格（小网段 1 像素 = 1 个地址，大网段自动合并采样）。网络地址、广播地址、首个/末个可用主机用不同颜色点亮，悬停任意像素可精确探查地址。
- **IPv4 宇宙小地图** — 全部 43 亿地址压成一张 256×256 的图（1 像素 = 一个 /16）。你的网段以青色高亮，特殊网段（RFC 1918 私有、回环、CGNAT、组播……）整体着色，一眼看清"邻居"。
- **信息面板** — 网络地址、掩码、反掩码、广播、首末主机、可用主机数、网段大小及其占整个 IPv4 空间的比例。
- **二进制视图** — 地址与掩码的 32 个比特，网络位与主机位双色标注。
- **类型徽章** — 私有 / 回环 / CGNAT / 组播 / TEST-NET / 公网，附定义它们的 RFC。
- **Copy report** 一键复制文本报告，或复制带 `?q=` 参数的分享链接；输入会写进 URL。

## 使用

输入或粘贴 `192.168.1.0/24`、`10.10.4.7/16`，或者不带前缀的 `8.8.8.8`（按 /32 处理），结果随输入实时更新。非法或越界输入会给友好的内联提示；带了主机位的地址会自动掩掉并提示。

## 隐私与技术

单个 `index.html`，零依赖、零构建、零网络请求。解析、位运算、渲染全部在浏览器 canvas 里本地完成，离线可用，双击文件即可运行。
