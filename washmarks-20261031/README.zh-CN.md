# WASHMARKS 洗标翻译官

**把衣服标签上的神秘符号翻译成人话——红线警告 + 娇气指数 + 洗标小测模式。**

**在线使用**：<https://xiangjianan.github.io/daily-tools/washmarks-20261031/>

## 解决什么问题

每件衣服的标签上都有 5 个 ISO 3758 洗护符号——水洗桶、三角、方块、熨斗、圆圈。几乎没人能流利读懂它们：你站在洗衣机前眯眼研究一个「画叉的方块圆圈」，猜错了就毁掉一件衣服。

## 怎么用

1. **点选五个槽位**（洗涤 / 漂白 / 干燥 / 熨烫 / 专业护理），从符号盘里挑一个和标签上一模一样的——5 个分类共 33 个手绘 SVG 符号。
2. **洗护卡自动生成**：每个分类一句人话（中英双语），禁忌项加粗标红，所有红线汇进一个警告框。
3. **娇气指数**（★☆☆☆☆–★★★★★）：把禁忌与温和程度折算成趣味判定——从「皮实耐造」到「祖宗级娇贵，建议供起来」。
4. **小测模式**：随机符号四选一（含同分类干扰项），连对计分——一分钟学会看洗标。

洗护卡可复制中文版或英文版（送干洗时 handy），清空即可解码下一件。

## 一句话价值

- 约 15 秒解码真实标签，不传图、不注册、不联网。
- 避开两大经典惨案：把「不可烘干」的衣服塞进烘衣机、用漂白剂洗掉印花。
- 顺便当 tiny trainer——小测玩几轮，以后自己就能读懂标签。

## 技术说明

- 单文件 `index.html`，零依赖、零构建，双击即用、离线可用。
- 33 个符号全部是内联 SVG，由少量可复用基元（水桶/三角/方块/熨斗/圆圈/画叉/横杠/圆点）拼出——无图片、无字体文件。
- 全程浏览器本地运行：状态就是一个 5 元素数组，数据不出页面。
- 原生 JS（约 300 行），响应式 CSS，键盘可访问（`Tab` + `Enter`），鼠标触屏双支持。
