# RampSmith · 色阶锻炉

粘**一个**品牌色，立刻在感知均匀的 **OKLCH** 空间锻出 50→950 共 11 级完整色阶——对比度徽章自带，一键导出。全程本地、零上传、零依赖。

**在线使用**：<https://xiangjianan.github.io/daily-tools/rampsmith-20261015/>

## 解决什么问题

手工调一套品牌色阶（类似 Tailwind 的 `blue-50 … blue-950`）是门玄学：sRGB 里做线性插值会得到发灰的中间调、发白的端点，还可能悄悄越出色域。大多数生成器的解法是让你把颜色上传到服务器。

## 怎么用

1. 往输入框丢任意颜色——`#hex`、`rgb()`、`hsl()`、`oklch()` 或取色器通吃。
2. RampSmith 锁定你的色相，套用一条手工调校的 OKLCH 明度曲线（专业色阶的感知奥秘）和「中间最艳、两端收敛」的彩度轮廓，再对色域边界做**二分收缩**，保证每一级都能真实显示。
3. 每级自带 WCAG 对比度徽章：对白底（`AA-W` / `AAA-W`）和对黑底（`AA-B` / `AAA-B`）；离你输入最近的一档挂 ★**品牌锚点**徽章。
4. 两根滑杆微调（整体彩度、明度偏移），真实 UI 预览（按钮 / 徽章 / 提示条），然后导出 CSS 变量、Tailwind v4 `@theme`、SCSS 或 JSON。

## 使用说明

- 点色阶任意一行复制该级 hex；点大按钮复制整套导出。
- 一切都在浏览器里完成：唯一的「网络请求」就是这个页面本身。无埋点，颜色永远不出本机。
- 鼠标触屏都支持，响应式适配到 360px。

## 技术说明

- 单文件 HTML + 原生 JS + CSS。零构建、零 CDN、零库。
- 色彩数学：Björn Ottosson 的 OKLab（CC0 协议）。sRGB↔OKLab 已对照公开真值验证（`#FF0000 → oklch(0.628 0.258 29.2)`，2000 组随机色往返误差为 0）。
- 色域安全：逐级对彩度做 22 轮二分搜索，贴着 sRGB 边界取值。
- 无头冒烟测试 26/26 通过（4 种格式解析、明度单调性、色域边界、剪贴板、移动端溢出、控制台零报错）。
